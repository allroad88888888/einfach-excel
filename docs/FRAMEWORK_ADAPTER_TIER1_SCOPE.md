# Framework adapter 档 1 范围

状态：范围冻结（AD-325）

本文定义未来 React 与 Vue 电子表格适配层的档 1目标行为边界。它是
面向后续实现和验收的范围基线，不是已有能力、兼容性或包可用性的说明。

## 适用对象

这份范围同时适用于未来的 React 和 Vue 适配层。两者应以相同的用户可见
行为为目标；具体组件结构、响应式桥接、样式组织、发布形态和实现次序不在
本文定义之内。

档 1 的目标是“能看能编”：用户能够查看工作表的可见部分、移动焦点和选区，
并完成基本的单元格输入与历史操作。任何行为只有在各自适配层实现并经过其
验收后，才能作为该框架的可用能力对外描述。

## 档 1 包含的行为

| 表面          | 目标行为边界                                                                 |
| ------------- | ---------------------------------------------------------------------------- |
| 网格          | 显示工作表的行、列和可见单元格，使用户能辨认当前工作区域。                   |
| 滚动          | 用户滚动时，网格可改为展示相应的可见工作表区域。                             |
| 冻结分区      | 配置了冻结行或列时，冻结区域在滚动其余区域时保持可见。                       |
| 选区          | 用户可看到活动单元格与当前选区，并通过支持的指针或键盘动作改变它们。         |
| 键盘导航      | 焦点在网格内时，支持基本的单元格间移动与编辑相关的键盘进入、退出动作。       |
| 单元格编辑    | 用户可开始、修改、提交或取消一个单元格的编辑会话，并获得与选区一致的结果。   |
| 输入法（IME） | 组合输入在组合结束前不应被当作最终编辑值提交或中断。                         |
| 公式栏        | 显示当前活动单元格的可编辑输入，并可作为编辑该单元格的入口。                 |
| 名称框        | 显示当前活动位置，并可作为进入已支持单元格位置的入口。                       |
| 工作表标签    | 显示可选择的工作表标签，用户可切换当前工作表。                               |
| 剪贴板        | 用户可对当前选区执行基本复制、剪切和粘贴，适配层将这些动作接入其工作簿边界。 |
| 撤销与重做    | 用户可请求撤销或重做可用的历史步骤，并看到由结果带来的界面更新。             |

“基本”只限定上述表面的存在和用户动作的连通性；它不预先规定快捷键集合、
鼠标手势、样式、无障碍细节、数据格式转换规则、错误呈现、跨浏览器策略或
性能指标。后续叶子在实现前可为其中某一表面补充更精确的行为契约，但不得把
未列出的产品功能默认为档 1内容。

## 档 1 明确排除项

以下表面不属于档 1；它们不能因与包含表面相邻而被视为本范围的一部分：

- 工具栏、菜单栏和状态栏；
- 所有对话框，包括格式、查找替换、打印、保护和数据处理对话框；
- 筛选、排序和其他专门数据处理 UI；
- 批注、协作 Presence 和其他多人协作 UI；
- 保护、权限、锁定策略与身份集成；
- 右键菜单；
- 工作表创建、删除、重命名、移动或其他管理 UI；
- 名称管理、命名范围管理与名称框以外的名称功能；
- 条件格式、图表、透视表、宏、插件和导入导出 UI；
- 档 1 之外的性能、可访问性、国际化或兼容性保证。

排除项并不判断这些能力是否在其他层、其他产品表面或现有 Solid 实现中存在；
只表示未来 React/Vue 档 1适配的目标范围不要求交付它们。

## 解释边界

本文不表示 React 或 Vue 适配已实现、可安装、可运行、兼容特定版本，或已获
支持。它也不构成发布日期、排期、维护等级、支持期限或功能对等承诺。

本文不重述 Solid 耦合点的事实审计，也不重述项目定位的事实边界；那些议题
分别属于 AD-311 和 AD-403 的交付。本文同样不实现样式层独立（AD-324），不
实现 React 适配（AD-330），也不实现 Vue 适配（AD-360）。

当本文与任何已实现适配层的证据发生差异时，应将已实现行为如实记录为其自身
的现状；不能据此反推另一个框架已有相同能力。对未来实现的取舍，以本范围为
起点，再由对应实现叶子和验收证据决定。
