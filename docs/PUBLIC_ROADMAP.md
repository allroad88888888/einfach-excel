# 对外路线图

状态：方向与边界（AD-710）

这份路线图说明可以公开讨论的工作方向及其前置条件。它不是发布日期、交付排期、
支持等级、兼容性说明或安装指南；任何框架或交付形态都只有在对应实现和验收完成后，
才能另行描述为可用。

## 当前基线

仓库当前的框架表面是 Solid：`@einfach/solid-excel` 的包元数据把自己描述为
SolidJS 组件，且其导出仍指向源码。React 和 Vue 是后续适配目标，不是已有的
对外能力。

对外分发仍受 AD-100 阻塞。其未裁决事项包括 Excel Core 的对外策略、WASM 的
分发形态、发布身份与凭据、版本策略和对外 Node.js 基线。它们决定可验证的交付
形态，不能由本路线图替代维护者决策。

## 交付方向

### 先闭合可验证的分发链路

在讨论新的框架表面前，AD-100 需要把选定的产物形态、依赖处理、版本协同和离体验证
落成可复核的交付链路。路线图不预设这些决策的具体方案，也不把仓库开发构建当作
对外交付证据。

### 再推进框架适配

React 和 Vue 适配共享 AD-310 的可移植性前置工作，随后分别由 AD-330 和 AD-360
推进；两条线完成后才进入 AD-390 的跨框架共享面。UI-core 保持无头且 DOM-free，
框架适配器继续拥有元素、事件、挂载和资源释放责任。

两种适配的档 1 目标边界相同：可见网格、滚动、冻结分区、选区、键盘导航、单元格编辑、
输入法、公式栏、名称框、工作表标签、剪贴板、撤销与重做。具体实现、组件结构、
响应式桥接、样式组织和交付形态由对应实施与验收决定。

## 档 1 以外的内容

以下不属于 React/Vue 档 1 的目标范围：工具栏、菜单栏、状态栏、对话框、筛选和排序
UI、批注与协作、保护与身份集成、右键菜单、工作表管理、名称管理、条件格式、图表、
透视表、宏、插件和导入导出 UI。档 1 也不包含额外的性能、可访问性、国际化或兼容性
保证。

这些排除项不评价它们是否存在于其他产品表面或当前 Solid 实现；它们只避免把未来
适配的未交付能力误写进路线图。
