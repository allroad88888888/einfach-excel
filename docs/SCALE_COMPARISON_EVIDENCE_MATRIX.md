# Scale comparison evidence matrix

This table collects the dated E3 records accepted for AD-815 and AD-816 using
the field vocabulary in [Scale comparison dimensions](SCALE_COMPARISON_DIMENSIONS.md).
It is a staging matrix, not a public-facing comparison, measurement report,
capacity statement, or product conclusion.

No row below has compatible E2 observations. Its comparability field is
therefore `not applicable`: it has no protocol, dataset shape, environment, or
configuration for a cross-subject result. The absence of a row or a source is
shown as E0 / `unknown`; it does not state that a subject lacks a mechanism.
