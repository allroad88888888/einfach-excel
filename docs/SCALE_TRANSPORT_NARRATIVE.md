# 规模、传输量与可替换后端：证据链叙事（AD-829）

一句话主张：**存储跟已填充格走，求值跟被读到的格走，载荷跟视口窗口走，而承载这
一切的后端端口不绑死任何一种运行时。** 下面每个论点只引用已入库的契约文档或
观察记录；本页不新造数字，也不与任何竞品比较。

## 1. 存储：内存对象跟已填充格，不跟表格矩形

[稀疏单元格存储模型](SPARSE_STORAGE_MODEL.md)（AD-803）记录了引擎侧
`RowMajorMap` 的契约：索引只含至少有一个已存储列的行、`len` 计已存储地址数而非
矩形格数，几何上的空格不占存储条目。

## 2. 依赖：范围依赖按 Tier 降级，登记量有界

[Range Dependency Tiers](RANGE_DEPENDENCY_TIERS.md)（AD-802）记录了公式读取时
范围依赖的选择规则与失效根：小范围逐格、大范围按带/按列降级。依赖登记的规模由
该规则约束，不随引用矩形无界展开。

## 3. 求值：只算被访问的格

[按需求值契约](ON_DEMAND_EVALUATION.md)（AD-821）记录了批量装载路径的公式
「停放 → 读取时水合求值」行为。
[AD-826 首屏实际公式求值观察](AD826_FIRST_SCREEN_EVALUATION_OBSERVATION.md)
用真实 worker 后端钉住了一次实测：96 格夹具、48 条浅层公式，首屏 12×4 读取后
两种后端（Rust/WASM 与 TS）的累计求值数都只从 0 变为 24——恰好是首屏范围内的
公式数，未被访问的另外 24 条没有被求值。

## 4. 载荷可计量：过线字节有统一口径

[AD-825 规范化 worker 载荷测量](AD825_WIRE_BYTES_MEASUREMENT.md) 定义了测量
方法 `canonical-json-utf8-v1`（稳定排序的 JSON、UTF-8 计字节、不可测消息单独
计数）。它是后续两条实测的仪器，本身不代表网络字节或性能。

## 5. 载荷有界：响应字节跟请求范围走

[AD-827 有界与全范围读取观察](AD827_BOUNDED_VS_FULL_RANGE_READ_OBSERVATION.md)
在同一夹具上实测：有界 12×4 读取的规范化载荷为 4,291 字节，显式全夹具 24×4 为
8,539 字节，两种 worker 后端数值一致——响应随请求的范围缩放，而不是随工作簿。

## 6. 后端可替换：同一套 UI 隔着网络也能浏览

`SpreadsheetBackend` 契约（`excel/spreadsheet-ui-core/src/backend/types.ts`）只
要求三个方法，其余端口按在位性降级；
[投影边界约束](PROJECTION_BOUNDARY_CONTRACT.md)（AD-824）记录了 UI 侧不留全簿
事实缓存、投影按窗口取的边界。这两条契约合起来使
[AD-828 跨网络后端的视口浏览观察](AD828_REMOTE_BACKEND_OBSERVATION.md) 成为
可能：一个只实现三必需方法的 HTTP 适配器对着 100,000 行 × 6 列（600,000 已填充
格）的远端内存工作簿，首屏加两轮滚动共 5 次请求、响应体合计 227,172 字节，而
同口径全簿序列化为 47,285,608 字节——载荷由视口窗口决定，工作簿总量只留在
服务端。

## 链条合拢

同一个机制在三个边界上给出同向的实测：worker 边界上响应随请求范围缩放
（AD-827），求值随访问范围推进（AD-826），HTTP 边界上响应随视口窗口缩放且后端
运行时可整体替换（AD-828）。支撑它们的存储、依赖与投影契约各自成文
（AD-802/803/824），可独立复核。

## 整链的解释边界

- 每条实测都限于其记录写明的单日、单修订、单浏览器与单一夹具；引用任何一条时
  必须连同其自身的解释边界。
- AD-828 的两端在同机回环上：链条证明的是**远程路径可行且载荷跟视口**，不构成
  任何真实网络下的延迟、带宽或吞吐结论；其服务端是无鉴权、无并发承诺的演示件。
- 载荷口径各自成文（AD-825 的规范化 JSON 字节、AD-828 的 HTTP 响应体字节），
  两者都不是 structured-clone 或链路层字节，不可互相替代或相加。
- 千万级证据另有边界：本链不覆盖千万级交互或容量结论，相关记录见
  [AD-807 观察](AD807_TEN_MILLION_LOAD_OBSERVATION.md)（一次失败边界观察）。
- 本链不含与任何竞品的对照；对比只能按
  [AD-800 的声明纪律](adoption-issues/AD-800-scale-differentiation.md) 另行取证。
