## 首版范围

React 与 Vue 首版只做档 1「能看能编」：网格、滚动、冻结分区、选区、键盘导航、编辑、IME、公式栏、名称框、工作表标签、复制粘贴与撤销重做。首版不做工具栏、全部对话框、筛选排序 UI、批注、协作 Presence、保护、右键菜单、菜单栏与状态栏。
