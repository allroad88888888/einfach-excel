# UI-300：发现命令并组织工作簿

父节点：[电子表格交互重整：Issue 树](../INTERACTION_ISSUE_TREE.md)

本父 Issue 聚合工作表结构和格式命令的发现、选择与返回工作区的路径；下列叶子 Issue 可独立推进。

## 叶子 Issue

### UI-301：工作表标签与工作表生命周期

- 入口 → 操作 → 界面衔接：通过标签切换、新建、重命名、复制、删除或移动工作表 → 更新当前工作区 → 接续网格操作。
- 涉及界面：`SpreadsheetSheetTabs`、标签溢出区、工作表上下文入口。
- 前置：UI-101。

### UI-302：行列、单元格与区域结构操作

- 入口 → 操作 → 界面衔接：选中行列或区域 → 插入、删除、移动、隐藏/显示或分组 → 回到更新后的可见范围。
- 涉及界面：行列标题、右键菜单、菜单栏、结构操作反馈。
- 前置：UI-103、UI-105、UI-304。

### UI-303：顶部菜单的命令导航

- 入口 → 操作 → 界面衔接：打开菜单栏 → 在分组、子菜单和快捷键提示中找到命令 → 执行后回到工作区。
- 涉及界面：`SpreadsheetMenuBar`、菜单层级、键盘菜单导航。
- 前置：UI-101。

### UI-304：右键菜单的上下文命令

- 入口 → 操作 → 界面衔接：在单元格、选区、行列或工作表上右键 → 得到对应命令 → 执行后保留可理解的焦点与选区。
- 涉及界面：`SpreadsheetContextMenu`、上下文命令分组、定位与关闭规则。
- 前置：UI-103、UI-105、UI-301。

### UI-305：工具栏的布局与命令可发现性

- 入口 → 操作 → 界面衔接：在工具栏浏览常用命令 → 在窄宽和溢出状态下定位命令 → 作用于当前选区。
- 涉及界面：`SpreadsheetToolbar`、分组、溢出、禁用态和当前态。
- 前置：UI-101、UI-103。

### UI-306：文本与填充格式工具

- 入口 → 操作 → 界面衔接：选中范围 → 调整字体、字号、粗斜体、颜色或填充 → 在工具栏和网格同时读到当前态。
- 涉及界面：字体、字号、颜色、填充下拉控件与单元格样式。
- 前置：UI-103、UI-305。

### UI-307：对齐、边框、合并与尺寸工具

- 入口 → 操作 → 界面衔接：选中范围 → 设置水平/垂直对齐、旋转、边框、合并或尺寸 → 回到可继续选择的网格。
- 涉及界面：对齐、旋转、边框、合并工具及网格几何。
- 前置：UI-103、UI-105、UI-106、UI-305。

### UI-308：数字格式快捷入口

- 入口 → 操作 → 界面衔接：选中数值范围 → 通过工具栏选择数字、日期、百分比、货币等格式 → 在单元格和工具栏确认当前态。
- 涉及界面：`NumberFormatDropdown`、当前格式显示、数字展示。
- 前置：UI-103、UI-305。

### UI-309：单元格格式对话框

- 入口 → 操作 → 界面衔接：从菜单或工具栏打开格式配置 → 在分组字段中编辑并预览 → 返回原选区。
- 涉及界面：`SpreadsheetFormatCellsDialog`、更多数字格式对话框、预览区。
- 前置：UI-103、UI-305、UI-505。
