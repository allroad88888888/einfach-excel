# UI-400：查找、整理和约束数据

父节点：[电子表格交互重整：Issue 树](../INTERACTION_ISSUE_TREE.md)

本父 Issue 聚合用户对现有数据进行定位、筛选、转换和施加规则的路径；下列叶子 Issue 可独立推进。

## 叶子 Issue

### UI-401：查找、替换与定位

- 入口 → 操作 → 界面衔接：从快捷键或菜单打开 → 输入查询、遍历命中、替换或直接定位 → 回到对应单元格。
- 涉及界面：`SpreadsheetFindReplaceDialog`、`SpreadsheetGoToDialog`、命中范围高亮。
- 前置：UI-102、UI-103、UI-505。

### UI-402：筛选条件与筛选结果

- 入口 → 操作 → 界面衔接：从表头或菜单打开筛选 → 选择条件 → 在网格、表头和状态区域识别当前筛选上下文。
- 涉及界面：`SpreadsheetFilterDropdown`、表头标记、隐藏行表现。
- 前置：UI-102、UI-105、UI-505。

### UI-403：排序范围与排序方向

- 入口 → 操作 → 界面衔接：在当前范围或表格上选择排序 → 明确字段和方向 → 回到重排后的范围并保留操作上下文。
- 涉及界面：菜单/工具栏排序入口、范围提示、排序结果反馈。
- 前置：UI-103、UI-303 或 UI-305。

### UI-404：文本分列

- 入口 → 操作 → 界面衔接：选中源列 → 选择分隔方式、格式和目标 → 完成配置后回到目标区域。
- 涉及界面：`SpreadsheetTextToColumnsDialog`、步骤区、源/目标范围提示。
- 前置：UI-103、UI-303、UI-505。

### UI-405：删除重复项

- 入口 → 操作 → 界面衔接：选中数据区域 → 选择参与字段 → 确认后回到整理后的数据范围。
- 涉及界面：`SpreadsheetRemoveDuplicatesDialog`、字段选择、范围提示、结果反馈。
- 前置：UI-103、UI-303、UI-505。

### UI-406：命名区域管理

- 入口 → 操作 → 界面衔接：从名称框、菜单或管理器浏览/新建/编辑名称 → 跳转或应用到范围 → 回到工作区。
- 涉及界面：名称框、`SpreadsheetNameManagerDialog`、引用范围提示。
- 前置：UI-103、UI-202、UI-505。

### UI-407：Excel 表格操作

- 入口 → 操作 → 界面衔接：从选区创建或操作表格 → 识别表格范围、表头和汇总行 → 回到表格内的筛选、编辑和结构操作。
- 涉及界面：表格命令入口、表格范围标识、表头/汇总行。
- 前置：UI-103、UI-302、UI-402。

### UI-408：条件格式规则

- 入口 → 操作 → 界面衔接：选中范围 → 创建、编辑、排序或删除规则 → 在网格中查看规则对应的视觉表达。
- 涉及界面：`SpreadsheetConditionalFormatDialog`、规则列表、网格条件格式层。
- 前置：UI-103、UI-107、UI-505。

### UI-409：数据验证规则与输入提示

- 入口 → 操作 → 界面衔接：选中范围 → 配置或编辑验证 → 输入时获得规则提示并回到编辑流程。
- 涉及界面：`SpreadsheetDataValidationDialog`、输入提示、无效输入提示。
- 前置：UI-107、UI-201、UI-505。
