# UI-500：在真实使用环境中完成任务

父节点：[电子表格交互重整：Issue 树](../INTERACTION_ISSUE_TREE.md)

本父 Issue 聚合协作、保护、输出、宿主生命周期与跨设备可达性；下列叶子 Issue 可独立推进。

## 叶子 Issue

### UI-501：批注线程

- 入口 → 操作 → 界面衔接：从单元格标记、右键或工具栏进入 → 阅读、回复或关闭线程 → 回到带上下文的单元格。
- 涉及界面：`SpreadsheetCommentThread`、单元格批注标记、批注入口。
- 前置：UI-103、UI-304、UI-505。

### UI-502：协作 Presence

- 入口 → 操作 → 界面衔接：在他人也处于工作簿时浏览和编辑 → 区分本地选区与他人位置 → 不打断当前操作。
- 涉及界面：`SpreadsheetPresenceOverlay`、身份标识、远端选区叠层。
- 前置：UI-103、UI-107。

### UI-503：受保护内容与解锁入口

- 入口 → 操作 → 界面衔接：尝试编辑或执行受限命令 → 理解限制位置与原因 → 打开解锁入口或回到允许的操作。
- 涉及界面：受保护单元格状态、`SpreadsheetProtectionUnlockDialog`、命令禁用态。
- 前置：UI-201、UI-305、UI-505。

### UI-504：打印预览与返回编辑

- 入口 → 操作 → 界面衔接：从菜单打开打印 → 调整范围或设置并查看预览 → 返回原工作区与选区。
- 涉及界面：`SpreadsheetPrintPreviewOverlay`、打印设置、返回入口。
- 前置：UI-303、UI-505。

### UI-505：所有对话框和浮层的共同行为

- 入口 → 操作 → 界面衔接：打开任意对话框、下拉菜单、Popover 或 Tooltip → 用鼠标/键盘完成或关闭 → 焦点精确回到发起位置。
- 涉及界面：遮罩、Esc、Tab 顺序、焦点陷阱、层级、溢出定位、未保存内容提示。
- 前置：UI-101。

### UI-506：状态栏、通知与诊断提示

- 入口 → 操作 → 界面衔接：进行选择、编辑、加载或遇到可解释状态 → 在不遮挡任务的区域得到反馈 → 回到当前任务。
- 涉及界面：`SpreadsheetStatusBar`、命令反馈、`SpreadsheetDiagnostics`、Spill 提示。
- 前置：UI-101、UI-103。

### UI-507：工作簿初始化、切换与后端能力呈现

- 入口 → 操作 → 界面衔接：宿主加载工作簿或切换静态/Worker/WASM 后端 → 进入可操作的工作区 → 在功能能力不同的情况下仍理解可用入口。
- 涉及界面：Provider/Adapter、初始工作表、能力关联的命令状态。
- 前置：UI-101、UI-305。

### UI-508：加载、中断与恢复路径

- 入口 → 操作 → 界面衔接：首次读取、异步请求、连接中断或恢复 → 知道当前界面是否可继续操作 → 恢复到正确的工作区上下文。
- 涉及界面：加载态、空态、局部失败提示、重试/恢复入口。
- 前置：UI-506、UI-507。

### UI-509：全键盘与读屏操作

- 入口 → 操作 → 界面衔接：不使用鼠标在网格、工具栏、菜单、对话框和状态区间移动 → 获知位置和状态 → 完成同一条操作链路。
- 涉及界面：焦点样式、ARIA 语义、快捷键、动态内容播报。
- 前置：UI-104、UI-303、UI-305、UI-505。

### UI-510：国际化、输入法与本地化输入

- 入口 → 操作 → 界面衔接：在不同语言、输入法、数字/日期区域设置下编辑和阅读 → 保持文本、快捷键和格式表达可理解 → 回到标准编辑流程。
- 涉及界面：文案、输入法组合态、数字日期格式、快捷键提示。
- 前置：UI-201、UI-202、UI-308、UI-509。

### UI-511：窄屏、触控与触控板使用

- 入口 → 操作 → 界面衔接：在小容器、触屏或触控板上选择、滚动、打开命令和配置 → 保持命中与可见性 → 继续原任务。
- 涉及界面：响应式工具栏、浮层定位、触摸命中区、手势、滚动表面。
- 前置：UI-102、UI-103、UI-305、UI-505。

### UI-517：打印设置的后端持久化与跨运行时一致性

- 入口 → 操作 → 界面衔接：在打印预览中打开页面设置并保存 → 切换 Static、WASM 或 TS Worker，或重新加载/导入导出工作簿 → 仍看到已确认的页面范围、分页与配置。
- 涉及界面：`SpreadsheetPageSetupDialog`、`SpreadsheetPrintPreviewOverlay`、Static/Worker backend adapter 与工作簿持久化路径。
- 前置：UI-504、UI-507、UI-516。
