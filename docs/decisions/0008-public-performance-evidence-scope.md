# ADR 0008：公共性能证据范围

- 状态：accepted
- 日期：2026-08-13
- 相关：[AD-500：可验证的性能证据](../adoption-issues/AD-500-performance.md)

## 背景

对外的性能表述必须能够被他人检查，且不能把架构机制、测试夹具的回归
观察值或内部基线误写成产品承诺。

[`excel/rust/docs/PERF.md`](../../excel/rust/docs/PERF.md) 服务于 Rust 核心的
内部相对比较。它不设绝对阈值，也不是公开基准的替代品。因此，公开证据的
类别先于测量方法、环境记录和结果发布确定。

## 决策

公共性能证据只涵盖以下四类：

1. **大表滚动流畅度**：用户在指定大表场景中的滚动体验。
2. **公式链重算延迟**：指定公式依赖链在输入变化后的重算体验。
3. **首屏到可交互**：指定入口从开始加载到可编辑的体验，包含适用时的
   WASM 获取与实例化。
4. **包体积**：指定可交付产物的体积。

这份决策只界定类别，不给任何类别预设数字、排名或结果。一次公开表述只有在
能指向其可检查的证据时，才可以使用上述类别名称。

## 披露边界

- 测量步骤、统计口径和采样规则由 AD-502 决定；本决策不选择中位数、分位数、
  轮数或预热规则。
- 哪些数字不构成承诺及其适用边界由 AD-503 决定；本决策不定义 SLO、SLA、
  回归门槛或生产性能保证。
- 机器、浏览器、版本和数据规模的记录格式由 AD-504 决定；本决策不规定测试
  环境或工作负载。
- 可复跑的脚本、原始结果、图表和发布位置由 AD-515 提供；在它们就绪前，四类
  仅是允许建设证据的范围，而不是已证实的宣传结论。

## 可验证性

任何公开结果都必须能关联到同一范围内的具体实现版本、场景定义、测量口径和
环境记录，并让读者取得复跑所需的脚本与结果。缺少其中任一项时，只能说明正在
建设该类证据，不能暗示性能已被独立验证。

现有行为或容量契约可以说明机制，但不能替代本决策范围内的测量证据。特别是，
测试夹具的诊断阈值、内部相对基线和历史报告都不得直接转写为公开性能数字。

## 不在范围

- 与其他产品的快慢、体积或资源消耗比较；
- 未按同一口径复跑的历史基准、截图或归档报告；
- 吞吐量、延迟、内存或可用性的生产保证；
- 架构上限、地址空间或有界性机制本身；
- 具体的基准实现、数据生成、结果导出、CI 门禁或变体取舍。

这些事项分别留给 AD-502 至 AD-517 的后续叶子；若以后需要扩大公开类别，应以
新的 ADR 更新此决策，而不是把未经复核的结果附加到这里。
