# ADR 0010：公共性能表述的非承诺边界

- 状态：accepted
- 日期：2026-08-13
- 相关：[AD-500：可验证的性能证据](../adoption-issues/AD-500-performance.md)
- 前置：[ADR 0008：公共性能证据范围](0008-public-performance-evidence-scope.md)、[ADR
  0009：公共性能测量方法](0009-public-performance-measurement-methodology.md)

## 背景

ADR 0008 规定可以建设为公共证据的性能类别，ADR 0009 规定如何取得可复跑的
样本。即使测量正确，读者也可能把某次运行的数字误解为所有机器、版本和工作负载
都必须达到的产品保证。

本决策限定公共性能表述的含义。它不选择环境记录字段、基准场景或结果发布方式，
也不提供任何性能结果。

## 决策

对外公布的滚动流畅度、公式链重算延迟、首屏到可交互和包体积数字，都是一次具名
运行的观测证据，而不是产品承诺。每个数字仅描述按 ADR 0009 的协议、在其关联的
实现版本、场景、数据档位与记录环境中取得的结果。

因此，公开数字不构成下列任何一项：

- 所有用户、机器、浏览器、网络条件或工作负载都应达到的最低性能；
- SLO、SLA、回归门槛、支持响应承诺或可用性保证；
- 未测场景、生产流量、最差情况或未来版本的预测；
- 与其他产品的速度、体积或资源消耗比较；
- 对地址空间、有界性或架构机制的容量保证。

同一实现也会随硬件能力、操作系统和浏览器版本、显示与电源设置、热状态、后台
负载、缓存状态、网络状况及场景数据而变化。数字可以用于检查该次运行，不能据此
推导这些条件之外的结果范围；本 ADR 不给出百分比波动、误差带或通用性能下限。

## 表述规则

公共材料引用性能数字时，必须将其表述为测得结果，而非“保证”“始终”“最低”或
“适用于全部环境”的结论。只有使用相同场景定义、完成条件、统计规则和可比环境
的运行，才可被并列比较；改变任一条件即为新的结果序列。

环境、版本、机器、浏览器与数据规模的记录格式由 AD-504 确定。该格式就绪前，不得
用未披露条件的数字暗示可迁移的范围。可复跑脚本、原始样本和结果发布由 AD-515
提供；它们未就绪时，只能说明正在建设性能证据，不能暗示已获得独立验证。

## 后果

后续性能结果页、宣传文案和比较材料必须保留本边界。若需要承诺具体性能水平，必须
另行作出带有适用条件、验证方法和维护责任的产品或服务决策，不能通过补充基准数字
隐含建立该承诺。

本决策不禁止内部诊断阈值或工程回归检查；它们不得直接改写为公共保证。具体基准、
体积口径、CI 门禁和竞争性对照仍分别属于 AD-505 至 AD-517 的后续叶子。
