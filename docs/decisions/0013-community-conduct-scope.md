# ADR 0013：社区行为准则的采用边界

- 状态：accepted
- 日期：2026-08-13
- 相关：[AD-705：`CODE_OF_CONDUCT.md`](../adoption-issues/AD-700-community.md)

## 背景

AD-705 要求评估仓库是否需要行为准则。行为准则不是只添加一份文本：它需要有受管的社区、
可归属的执行责任，以及面向行为问题的报告路径。当前仓库没有这些前提。

## 决策

仓库暂不添加 `CODE_OF_CONDUCT.md`。原因是当前没有受管的社区、执行机制或面向行为问题的
报告路径；在这些条件缺失时，发布行为准则会暗示仓库能够承接报告或实施规则，而事实并非如此。

本 ADR 不采纳任何行为准则，也不建立报告渠道、GitHub 配置、SLA、响应承诺或执行承诺。

## 后果

仓库不会因为此 ADR 而对社区行为、举报处理、处理时限或处置结果作出对外承诺。若以后考虑
引入行为准则，必须以新的决策先明确受管社区、责任归属和报告路径；本 ADR 不预先规定其内容。

## 不在范围

- `CODE_OF_CONDUCT.md` 的文本、采用或发布；
- 任何报告邮箱、issue、discussion 或其他报告渠道；
- GitHub 配置、SLA、响应流程、调查、处置或申诉机制；
- 对贡献者、使用者或其他第三方的行为或执行承诺。
