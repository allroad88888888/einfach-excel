# UI-100：进入并操控网格

父节点：[电子表格交互重整：Issue 树](../INTERACTION_ISSUE_TREE.md)

本父 Issue 聚合用户从看到工作簿到在网格中定位、选择和理解空间关系的路径；下列叶子 Issue 可独立推进。

## 叶子 Issue

### UI-101：首屏工作区与初始焦点

- 入口 → 操作 → 界面衔接：打开或返回工作簿 → 识别当前工作表与活动单元格 → 在网格、公式栏、工具栏、标签和状态栏之间开始操作。
- 涉及界面：`SpreadsheetUiProvider`、`SpreadsheetGrid`、公式栏、工具栏、工作表标签、状态栏。
- 前置：无。

### UI-102：大表滚动与视口连续性

- 入口 → 操作 → 界面衔接：在任意位置滚动、拖动滚动条或跳转远处 → 继续浏览并保持当前操作上下文 → 回到编辑或选择。
- 涉及界面：网格滚动表面、虚拟窗口、滚动锚定、横纵滚动条。
- 前置：UI-101。

### UI-103：鼠标选区与多区域选择

- 入口 → 操作 → 界面衔接：点击、拖拽、Shift/Ctrl（或等价修饰键）扩选 → 看见活动格和所有选区 → 交给编辑、格式、复制或右键命令。
- 涉及界面：单元格命中、选区边框、选区叠层、填充柄、右键前置选中。
- 前置：UI-101、UI-102。

### UI-104：键盘导航与视口跟随

- 入口 → 操作 → 界面衔接：以方向键、Tab、Enter、Home/End、Page 键移动 → 选区与视口同步移动 → 接续输入、复制和命令操作。
- 涉及界面：网格焦点、键盘控制器、活动单元格、滚动跟随。
- 前置：UI-101、UI-102、UI-103。

### UI-105：行列标题、尺寸调整与自动适配

- 入口 → 操作 → 界面衔接：在行头、列头或全选角操作 → 选择整行列、调整尺寸或自动适配 → 回到包含该范围的网格操作。
- 涉及界面：行头、列头、全选角、调整手柄、自动适配反馈。
- 前置：UI-102、UI-103。

### UI-106：冻结、合并与分级显示的空间关系

- 入口 → 操作 → 界面衔接：设置或遇到冻结、合并、Outline 区域 → 在滚动和选择时理解区域关系 → 继续编辑和结构操作。
- 涉及界面：冻结分区、合并区域、Outline 控件、网格叠层。
- 前置：UI-102、UI-103、UI-105。

### UI-107：特殊单元格与网格提示层

- 入口 → 操作 → 界面衔接：浏览包含溢出、条件格式、数据验证或富类型内容的格子 → 识别状态和可操作入口 → 回到当前选择或编辑。
- 涉及界面：单元格显示、溢出/Spill 提示、验证提示、条件格式视觉层。
- 前置：UI-101、UI-103。
