# UI-200：输入、计算与复用内容

父节点：[电子表格交互重整：Issue 树](../INTERACTION_ISSUE_TREE.md)

本父 Issue 聚合从单元格输入、公式构造到复制和回退内容操作的路径；下列叶子 Issue 可独立推进。

## 叶子 Issue

### UI-201：单元格直接编辑

- 入口 → 操作 → 界面衔接：从已选单元格按键或双击进入 → 输入、提交、取消或连续移动 → 回到选区和网格导航。
- 涉及界面：单元格编辑器、编辑态样式、提交/取消键盘路径。
- 前置：UI-103、UI-104。

### UI-202：公式栏与名称框

- 入口 → 操作 → 界面衔接：查看或编辑活动格内容，或输入地址/名称 → 定位目标区域并同步编辑状态 → 返回网格。
- 涉及界面：`SpreadsheetFormulaBar`、`SpreadsheetNameBox`、活动单元格同步。
- 前置：UI-101、UI-103、UI-201。

### UI-203：公式引用拾取

- 入口 → 操作 → 界面衔接：在公式输入中点击或拖拽网格范围 → 将引用插入当前位置并高亮来源 → 继续公式编辑或提交。
- 涉及界面：公式编辑器、引用颜色、范围叠层、多区域引用。
- 前置：UI-103、UI-201、UI-202。

### UI-204：公式建议与自定义函数提示

- 入口 → 操作 → 界面衔接：输入函数名或参数 → 浏览、键盘选择或接受建议 → 回到公式编辑并继续输入。
- 涉及界面：`SpreadsheetFormulaAutocomplete`、函数签名提示、自定义函数提示。
- 前置：UI-201、UI-202。

### UI-205：复制、剪切与普通粘贴

- 入口 → 操作 → 界面衔接：选中来源范围并复制/剪切 → 选择目标 → 粘贴后保留可理解的选择和复制状态。
- 涉及界面：复制边框、系统剪贴板、快捷键、网格目标范围。
- 前置：UI-103、UI-104。

### UI-206：选择性粘贴

- 入口 → 操作 → 界面衔接：复制来源 → 打开选择性粘贴 → 选择内容类型或操作 → 返回目标范围。
- 涉及界面：`SpreadsheetPasteSpecialDialog`、粘贴选项、目标范围提示。
- 前置：UI-205、UI-505。

### UI-207：填充柄与序列填充

- 入口 → 操作 → 界面衔接：选中源范围 → 拖动填充柄或选择填充方向 → 看到目标范围 → 继续编辑或格式化。
- 涉及界面：填充柄、拖拽预览、目标区域高亮。
- 前置：UI-103、UI-105。

### UI-208：格式刷

- 入口 → 操作 → 界面衔接：从来源范围开启格式刷 → 点选或拖过目标范围 → 继续应用或退出该模式。
- 涉及界面：`SpreadsheetFormatPainter`、工具栏按钮、网格光标和模式提示。
- 前置：UI-103、UI-305。

### UI-209：撤销、重做与历史回看

- 入口 → 操作 → 界面衔接：操作后使用快捷键、工具栏或时间线回看 → 选择撤销/重做目标 → 回到当前工作区。
- 涉及界面：撤销/重做按钮、`SpreadsheetHistoryTimeline`、命令反馈。
- 前置：UI-201、UI-205、UI-207。

### UI-210：Copy As 导出

- 入口 → 操作 → 界面衔接：选中范围 → 选择导出格式 → 把结果交给系统剪贴板或宿主 → 保持原选区。
- 涉及界面：Copy As 菜单入口、格式选择、导出反馈。
- 前置：UI-103、UI-303 或 UI-304。
