对照 Office Excel 的 DrawingML 图表格式，列出 @einfach-excel/xlsx（独立 WASM 包，XLSX ⇄ .einfach.json）读写图表的范围。转换器把图表 XML 映射成浮动对象目录里 kind=chart 的载荷，载荷字段与 plugin-chart 共用；核心仍不认识图表。目标是常见类型「读得进、写得出、改得动」，不追求高保真往返。左侧徽标是实现归属，右侧是实现进度（核对至 worktree-charts@76c421b5，issue #18）。
