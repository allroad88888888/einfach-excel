演示步骤

  1. 1
    导出 A → 改一格 → 导出 B → diff

    点击任意单元格（数字）+100，看 diff 如何标记变化行。

  2. 2
    回灌 A 并看 roundtrip ✓

    点「回灌快照 A」，表格还原，自动重新导出到 B 并 diff，校验应为 0 行。

  3. 3
    跑同步与分批各一次

    点两个导出按钮，记录耗时与停顿。同步会卡，分批流畅。

设计亮点

真实实现里快照序列化发生在 worker，主线程只收字符串；回灌走分批 setSheetsData，revision 保证不覆盖回灌期间的新编辑。
