只算用得着的

另一半机制：物化闸门

稀疏路径解决「聚合类」整列公式；对必须整块摊平的函数，引擎在物化口设闸。

=SUMIF(A:A,"电子",B:B)
✓ 稀疏路径求值

聚合函数不需要把整列摊成数组——逐真实格遍历即可，一百万格的名义区域只是几何，不是成本。

=SORT(A:A)
#NUM! 拒绝物化

排序必须拿到整块矩形。超过上限的物化请求被闸门以带外标记拒绝，折成标量错误冒出——而不是挂死 worker。

闸门的不变式：一个矩形物化得动，当且仅当它作为数组结果落得了地。落不了地的，物化它纯属白干。—— range-gate.ts

它是怎么做到的

整列引用在求值器里保持为几何描述而非数据：条件聚合家族走稀疏孪生（只遍历存量单元格）， 需要整块物化的函数则经过物化闸门审查。两条路径共用同一套引用几何， 所以 A:A 写起来和 Excel 一样，跑起来和数据量一样。
