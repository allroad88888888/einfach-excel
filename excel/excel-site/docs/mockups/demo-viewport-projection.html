试试这个

每一步做完会自动打勾——不是读完照做的说明文，是可验证的引导。

  1. 1滚动一屏

    用滚轮或拖动滚动条。注意「投影窗口」跟着走，而「DOM 行节点」几乎不变。

  2. 2跳到表格深处

    名称框输入 F45000 跳转——落点行会闪烁。九万行外的跳转和第一屏一样快。

  3. 3在深处改一个格

    把 E45000（数量）+10。金额列 G45000 与全表汇总一起更新——重算只触碰 2 个格子和 1 个聚合。

它是怎么做到的

正文静态渲染，爬虫和 AI 都读得到；下面的链接在真实站点指向源码与 API 文档。

UI 层持有的只是一个可视窗口投影：滚动改变 ViewportMetrics， backend port 的 readVisibleProjection 返回窗口内的格子——协议上不存在 「把整张表交给前端」这条路。数据、公式与依赖图都留在 Web Worker 里的 Rust/WASM 工作簿中。
