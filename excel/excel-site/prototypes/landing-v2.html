01 / PRODUCT THESIS

为了你的业务流程而生，
不是复刻一个桌面 Excel。

01

在数据真正变大前，先把边界立起来。

视口投影让渲染层只处理用户看得见的单元格。你的 UI 不必把完整工作簿塞进浏览器。

体验投影视口 →

02

让计算留在后台。

Rust/WASM 工作簿运行于 Web Worker，主线程继续接住滚动、编辑与键盘交互。

看运行时边界 →

03

保留你的数据主权。

框架无关的 UI 核心通过后端端口读写工作簿，适合接入已有服务或本地模型。

阅读架构说明 →
