## Try this

1. Select a range and make an edit.
2. Use the toolbar to apply a data operation.
3. Undo the operation and continue editing.

## How it works

The chrome composes optional UI capabilities around a single backend. This skeleton uses the real worker path so later scenario seeds can demonstrate data tools without replacing the grid architecture.
