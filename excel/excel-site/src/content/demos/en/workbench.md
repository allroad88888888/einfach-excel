## Try this

1. Select a cell and type a value.
2. Use the formula bar or name box to move around.
3. Inspect the toolbar, sheet tabs, and status bar as one composed experience.

## How it works

The workbench is a composition reference: the provider wraps chrome and grid exactly once, while each host chooses which optional capabilities and dialogs to include.
