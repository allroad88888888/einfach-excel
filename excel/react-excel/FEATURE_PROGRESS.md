## 范围与完成口径

- 产品目标：**单用户、可嵌入宿主的本地表格组件，不是在线协作表格**（2026-10-29 用户裁定）。
  协作、身份/通知、更改记录、版本历史、个人视图、自动保存与服务端持久化全部暂停，不计入剩余工作。
- 核对索引沿用[历史在线 Excel 清单](../solid-excel/docs/archive/online-excel-parity/README.md)的 41 项，
  只引用功能范围，不继承 Solid 的实现或架构。
- 记为"完成"需要三样：React 入口、真实 Rust 行为、可复现的 E2E 主用例。只有核心单测或部分入口记为"部分"。
- 本页状态于 2026-10-29 对照源码重新核实；"缺"表示在 excel-core / ui-core / react-excel 三层都没找到实现。
