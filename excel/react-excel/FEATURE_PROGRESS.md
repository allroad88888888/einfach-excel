## 范围与完成口径

- 产品目标：**单用户、可嵌入宿主的本地表格组件，不是在线协作表格**（2026-10-29 用户裁定）。
  协作、身份/通知、更改记录、版本历史、个人视图、自动保存与服务端持久化全部暂停，不计入剩余工作。
- 核对索引沿用[历史在线 Excel 清单](../solid-excel/docs/archive/online-excel-parity/README.md)的 41 项，
  只引用功能范围，不继承 Solid 的实现或架构。
- 记为"完成"需要三样：React 入口、真实 Rust 行为、可复现的 E2E 主用例。只有核心单测或部分入口记为"部分"。
- 本页状态于 2026-10-29 对照源码重新核实；"缺"表示在 excel-core / ui-core / react-excel 三层都没找到实现。

## 细项缺口（按优先级）

Luckysheet 差距表中的宿主基础 API、修改前拦截与交互订阅、Canvas 绘制钩子、
逐按钮显隐和标题尺寸配置已接入主线，契约见 [Workbook API](docs/package/workbook-api.md)。
单元格分段富文本（原生历史、编辑器、DOM/Canvas、文件与 XLSX）、可嵌套暂停绘制／计算、
宿主高亮区域、可见性查询和函数参数面板入口已接入。完成编译和集中冒烟检查，新增单测按用户安排后续统一补充。
富文本分段上下标通过可选文字格式插件编辑，复用共享草稿与保存事务，支持显式正常基线和整格继承。
HTML 复制保留分段字形样式；Table 内富文本编辑仍待补。
缩小字体填充通过同一可选文字格式插件提供；与换行互斥的操作只有一次原生历史，显示缩放不修改
原字号、数值或公式。DOM/Canvas/PNG 共用适用性规则，原生/XLSX 保留行列继承及显式关闭。
斜线编辑通过可选单元格外观插件进入共享边框面板，无独立可变草稿。无插件仍显示、复制与保存已有斜线；
单一连续范围最多 100,000 格，合并格按完整矩形绘制；XLSX 轴级斜线仍沿现有损失报告，不承诺保真。
图案填充通过同一外观插件提供全部 17 种图案及独立双色输入，草稿与反馈归插件 `/core`。
固色及无填充入口一次清除图案，背景条件格式仅临时覆盖；DOM/Canvas/PNG 共用逻辑图块。
原生/XLSX 支持稀疏行列与显式清除；XLSX 不可表达的独立双色继承明确报损。
线性与矩形渐变也通过外观插件编辑。切换类型保留会话参数和导入的完整色标，应用走一次原生历史。
DOM/Canvas/PNG 保留完整格尺寸下的渐变几何，原生/XLSX 保留原始参数与色标顺序。
分类汇总通过可选 `data-subtotal` 插件提供创建、替换、追加及删除（SUBTOTAL-001–009）。
原生工作簿保存公式、大纲与生成行归属，完整变更一次撤销。
合并计算通过可选 `data-consolidate` 插件提供按位置及首行/最左列二维分类合并（CONSOLIDATE-001–004）。
支持全部 11 种汇总函数、跨表/命名区域引用、预览与覆盖确认、创建指向源数据的链接公式与行大纲，一次原子撤销。
