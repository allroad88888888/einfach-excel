# React Excel

一个独立运行的 Vite 工作簿演示站。站点外壳负责选择 demo；当前第一个 demo 是由 Einfach
Rust/WASM 引擎驱动的销售订单工作簿。

## 当前能力

工作簿启动后会向 Rust 引擎导入 1,000 条销售订单记录。界面只渲染当前可见的 32 行窗口，
不会一次挂载整张工作表。目前支持：

- 单元格单选和拖拽框选；
- 新增空白工作表、切换标签、重命名、删除与左右移动（含静态跨表公式引用随动）；
- 点击行号选择整行、点击列名选择整列、点击左上角选择整表；
- 设置所选行的行高、所选列的列宽、恢复所选行列的默认尺寸；
- 清除选区内容（也支持 Delete）、清除格式、全部清除；
- 系统剪贴板复制、同表剪切、矩形粘贴（工具栏与 Ctrl/⌘+C、X、V）；
- `Copy as`：复制为纯文本、Markdown、HTML 表格；
- 仅粘贴值、仅粘贴格式，以及将复制内容重复铺满矩形选区；
- 转置粘贴、跳过空白、粘贴值及格式（工具栏 `Paste options` 下拉菜单）；
- 粘贴加、减、乘、除：批量运算保留公式依赖，可一步撤销/重做；
- `Paste special` 组合粘贴选项；仅粘贴列宽，可恢复目标的默认列宽；
- 仅公式、公式及数字格式、值及数字格式（同一个下拉菜单）；
- 从首行滚动到最后一条记录；
- 双击单元格或按 Enter 进入编辑；
- 在名称框输入单元格地址，跳转选区和可见窗口；
- 在公式栏直接修改活动单元格；
- 按 Enter 或失焦后，通过一次 Rust command 同时写入并取得当前可见投影；
- 按 Escape 取消编辑，不产生写入；
- 原始数值编辑（公式栏和格内编辑不使用经过货币、百分比或 General 舍入的显示文本）；
- 前导 `'` 强制文本、TRUE/FALSE 布尔值、百分比输入，由 Rust 统一识别；
- 两种编辑入口均支持 Alt+Enter 在光标处换行，Enter 提交；输入法组合确认键不触发提交或取消；
- 通过工具栏设置字体、颜色、边框、对齐、旋转、缩进等单元格格式；
- 百分比、货币、千分位格式，以及增加小数位、减少小数位、恢复常规格式。

数字格式只影响显示，不改原始数值或公式。小数位按钮范围为 0–15 位，沿用活动单元格的
数字格式应用到选区；恢复常规格式不会清除字体、颜色或边框。可在名称框跳转到 `O4`
（初始 `10.00%`）、`P3`（初始粗体 `$125`，原值 `125.02`）和 `G9`（初始 `2,632.00`）测试。

表头支持 Shift 点击连续选择多行或多列，名称框和底部 Count 显示完整选区。整行格式写到
Rust `rowStyle`，整列格式写到 `columnStyle`；交叉位置遵循后一次操作生效的规则。
点击表头会显示活动格（整行的首列、整列的首行、整表的 A1），便于回显格式和继续键盘编辑。
编辑中点击表头会先提交当前值，失败时保留草稿。

选中单元格区域后，点击工具栏 `↔`（`Row and column size`）打开尺寸面板。
行高支持 16–512 像素，列宽支持 40–1024 像素，按整数输入；分别点击对应的设置按钮。
例如选中 `B2:C4` 设置行高，会作用到第 2–4 行；设置列宽，会作用到 B、C 列。
`Reset selected sizes` 清除这几行/列的尺寸覆盖，恢复当前 demo 默认的 28px 行高、120px 列宽，
不删除内容、公式或字体颜色。恢复默认尺寸不是自动适应内容；手动缩小的行会裁切大字。
`Summary` 的第 1 行初始 40px、A 列初始 200px，可直接对比测试；尺寸种子仍在页面 data 目录。
行高由 Rust `rowStyle.height` 持有，列宽沿用 Rust 的稀疏列尺寸元数据，不逐格创建样式。
输入草稿未提交时尺寸入口禁用；受保护工作表拒绝尺寸修改。拖拽调尺寸、自动适应和隐藏/恢复仍待补。

工具栏的 `Clear contents` 保留格式，`Clear formatting` 保留数值与公式，`Clear all` 清除两者。
清除格式不会重置行高/列宽，且可覆盖选区内继承的行列样式；再次设置行列格式时仍以后一次
操作为准。编辑草稿打开时，三个清除按钮禁用，避免意外丢弃未提交输入。
持续执行范围与批次证据见[主线执行记录](./FEATURE_PROGRESS.md)。

底部 `＋` 新增空白工作表，沿用当前表的画布行列数；不会复制数据或创建新的 Worker。
点击标签或左右按钮切表，当前版本回到目标表的 A1，不保留每张表的滚动位置。
切表前提交当前格内/公式栏草稿；提交失败则留在原表，保留草稿供修正。
双击标签、对焦标签后按 F2，或点击铅笔按钮可重命名；Enter 保存，Escape/Cancel 取消。
Rust 校验空名、31 字符限制、非法字符、重复名称与保留名称；错误留在输入框下，可修改重试。
命名限制参考 [Microsoft 工作表重命名规则](https://support.microsoft.com/en-us/excel/rename-a-worksheet)。

原始工作簿增加 `Summary` 示例表：B1 引用订单表 G2（初始 79），B2 引用订单表 B2（Acme Co.）。
把 `Sales Orders` 改名后，这两条公式仍应正确；修改订单表 E2 数量后，Summary 的金额继续重算。
公式改写发生在 Rust 的稀疏公式索引中，不扫描全部空白格，不修改普通文字里的表名。
当前只接通单元格静态公式引用；命名公式、规则表达式及既有剪贴板快照的改名随动仍待补。
底部左右移动按钮调整当前表顺序并保留选区；删除按钮需要确认，至少保留一张表。
当前表删除后切换到邻表，静态公式引用变为 `#REF!`；撤销可恢复原表及引用，重建同名新表不会恢复旧引用。
剪贴板来源随表顺序变化更新；来源被删除时拒绝粘贴，公式引用随改名或删除更新。
持久化恢复与每表视图记忆尚未接通，不将当前标签操作视为工作表管理全部完成。

复制时 Rust 保存值、公式及有效格式快照，之后修改源格不会修改该快照。内部粘贴保留格式，
相对公式引用随目标位置平移；普通粘贴不会复制行高和列宽。剪切先保留源格，成功粘贴时才移动，
同表单元格引用跟随移动；失败时不删除源格。同一次剪切只能落地一次。

外部 TSV 支持多行、多列、引号内换行、空格子、数字、布尔值和公式，不覆盖目标格式。
权限失败会在底部提示；工具栏读取权限被拒绝时，可在网格按 Ctrl/⌘+V。编辑器打开时
剪贴板按钮禁用，输入框内仍使用原生文字复制粘贴。复制 `A2` 可验证粗体，复制 `G2` 到 `G3`
可验证公式平移，剪切 `E2` 到 `E4` 可验证 `G2` 的引用跟随，无需添加另一份测试数据。

`Paste values only` 保留目标格式，公式转为复制时的计算结果，不使用经过显示格式舍入的文本。
例如复制 `P3` 到 `B3`，仅粘贴值会得到 `125.02`，而不是 `125`。
`Paste formatting only` 只写格式，不改目标数值或公式；复制 `P3` 的格式到 `G9` 可验证。
外部文本的仅值粘贴不会执行公式；仅格式粘贴要求当前工作簿的内部复制快照。

单格目标会展开为复制内容的尺寸；较大选区的行列数必须分别是源区域的整数倍，否则整次拒绝。
例如复制 `A2:C2`，选择 `A10:F11` 后粘贴，会重复填满选区，公式按各目标位置平移。
剪切不支持重复填充或选择性粘贴，拒绝时仍保留源格。
`Paste options` 提供以下一次性操作，选择后立即粘贴，不改变下一次普通粘贴的行为：

- `Paste and add / subtract / multiply / divide` 分别计算「目标 + / − / × / ÷ 复制内容」。复制 `E4`（3）到
  `E10`（9）可得到 12 / 6 / 27 / 3。内部复制同时带源格式，外部 TSV 保留目标格式，不复制行高/列宽。
  公式保留为组合表达式，源公式先平移引用；复制 `G2` 到 `G3` 做加法后，修改 `E3` 仍会重算。
  空白按 0、布尔按 1/0、数字文字按数字运算；非数字文字产生 `#VALUE!`，溢出产生 `#NUM!`，可撤销恢复。
  除以 0 产生 `#DIV/0!`，同样可以撤销。
- `Paste transposed` 交换源区域的行列，数值与格式一起转置；公式按各源格到目标格的偏移调整，
  绝对引用保持不变。复制 `A2:C3` 到 `A10` 会得到 3 行、2 列，也可以按转置后的尺寸平铺。
- `Paste skipping blanks` 保留空白源格对应的目标内容与格式；`0`、`false`、空字符串和
  返回空字符串的公式不是空格。先清空 `A2` 内容，再复制 `A2:B2` 到 `A10` 可测试。
- `Paste values and formatting` 保留复制时的原始数值/计算结果及样式，不保留公式。
  复制 `P3` 到 `B3` 仍显示粗体 `$125`，清除目标格式后可看到原始值 `125.02`。
- `Paste formulas only` 保留公式并平移相对引用，不覆盖目标格式；混合区域里的常量仍会复制，
  不是只筛选公式格。可复制 `G2` 到 `G3`，目标不会被源格的 Georgia 字体覆盖。
- `Paste formulas and number formats` 保留公式，同时只复制数字格式；不改目标字体、颜色等。
  复制 `G9` 到 `G10`，显示 `1,341.00`，公式变为 `E10*F10`，修改 `E10` 仍会重算。
- `Paste values and number formats` 把公式变成复制时的计算结果，只携带数字格式。
  复制 `P3` 到 `B2` 显示 `$125`，保留 B2 原有斜体、不带源粗体；原始值仍是 `125.02`。

`Paste special` 面板可组合内容模式、加减乘除、转置和跳过空白，一次确认只产生一条粘贴历史。
失败保留选项以便重试，取消或成功后恢复默认；等待权限时控件禁用，不允许重复提交。
`Column widths only` 只修改目标列属性，不改内容、格式或行高；只接受本工作簿的复制快照，
不能配合运算、转置、跳过空白或剪切，受保护的工作表需先解除保护。
例如复制 Summary 的 `A1:B2` 到 Sales Orders 的 `B4`，B 列变为 200px，C 列恢复默认宽度；
列宽在复制时冻结，选多列时按源列数平铺，可撤销/重做，屏幕外列同步更新。

外部 TSV 支持转置、跳过空白、公式粘贴；外部公式按原文引用，不凭空猜测源坐标。
它没有源样式，因此“值及格式”和两种“数字格式”粘贴会明确拒绝。
剪切不接受以上特殊粘贴操作，拒绝后可以继续普通粘贴。跨表剪切、部分公式范围移动、多区域、
Copy As 图片及完整合并/筛选导出、批注粘贴等能力仍待接入。
单次操作上限为 1,048,576 格、文本 16 MiB，越过当前工作表边界会拒绝。

`Copy as` 从 Rust 读取完整选区，不受屏幕只挂载 32 行限制；它复制显示结果，不保存公式：

- `Copy as plain text`：输出 TSV，去掉样式，格内换行和制表符折为一个空格。`P3` 得到 `$125`；
  需要原始值 `125.02` 时用普通复制加“仅粘贴值”，不要用显示文本导出。
- `Copy as Markdown`：首行为表头，保留粗体/斜体，换行转为 `<br>`，特殊字符按文本转义。
  选中 `A2:C3` 可看到 Markdown 表格；不保留颜色等 Markdown 无法表达的样式。
- `Copy as HTML table`：生成带字体、颜色、对齐等基础样式的 HTML 表格，同时提供纯文本版本。
  选中 `A2:F2` 验证原始种子的粗体、斜体、下划线、背景色和文字颜色；`I3` 可验证多行文本。

三种操作共用现有剪贴板反馈，未提交草稿存在时禁用。失败可重新选择同一个选项重试。
导出不改变选区投影、不覆盖原 Rust 剪切快照，也不携带内部 token；粘回本表时按外部文本处理，
不会意外变成移动源格。HTML 格式能否保留取决于接收应用，本表目前不导入外部 HTML 样式。
Copy As 单次上限为 100,000 格、最终文本共 16 MiB，超限拒绝而不是只复制前一部分。
过滤行、合并、列宽行高及 PNG 导出仍需后续接入真实 Rust 投影，不据此宣称完整导出兼容性。

工作表标签与本地操作历史已接入；缩放区域仍主要负责界面展示，持久化版本历史尚未接入。
编辑来源已与显示文本分开：例如 `P3` 显示 `$125`，进入编辑及公式栏显示的是 `125.02`；
`O4` 显示 `10.00%`，编辑值为 `0.1`。直接 Enter 或失焦不会把显示舍入写回原值。
`I3` 是原始种子里的两行示例 `Noah` / `East team`。格内和公式栏都能用 Alt+Enter 换行，
也可替换当前选中的文字；保存后只撑高所在行，行高仍只属于 Rust `rowStyle`，不会自动缩小。
目前行高按显式换行数估算，不代表已经完成按列宽自动折行的完整 AutoFit。
输入法已覆盖浏览器组合事件和 `229` 确认键保护，真实系统候选窗仍需手工验收。

输入类型可在格内或公式栏直接测试：

- 输入 `'00123`，显示 `00123`，保留前导零；重新编辑时补回输入标记，仍是文本。
  `'=1+2` 保存文字而不是公式；单独输入 `'` 保存空字符串，清空输入才删除内容。
- 输入 `true` / `FALSE`，保存真正的布尔值，显示为 `TRUE` / `FALSE`；支持大小写及外围空格。
- 输入 `12.50%`，保存数字 `0.125`，同时设置当前格百分比格式为两位小数；其他样式保留。
  再次编辑显示 `0.125`，直接提交不会丢失百分比格式。外部 TSV 同样识别百分比数值，但保留目标格式。

原始种子的 `A4` 是文本 `00123`，`H4` 是布尔值 `TRUE`，`O4` 是百分比示例。
日期、时间、地区化数字格式等完整输入类型尚未实现；无法识别的输入保留为文字。
公式解析或静态循环检查失败时保留原数据；两种编辑入口都显示失败提示，Escape 可取消草稿。

## Rust-only 运行边界

```text
React 视图
  → @einfach/react（useAtomValue / useSetAtom）
  → @einfach/spreadsheet-ui-core（状态 atom / command atom）
  → rustWorkbookConnectionAtom
  → @einfach/spreadsheet-ui-core/rust-worker（纯传输）
  → Rust/WASM workbook
```

类型化工作簿命令与轻量 Rust/WASM runtime 均由 UI-core 所有。React 不依赖
`@einfach/solid-excel`；生产路径没有 `SpreadsheetBackend`、TypeScript engine 或运行时 fallback。

- Rust/WASM 负责工作簿权威数据、计算和 mutation 结果。
- `spreadsheet-ui-core` 负责创建连接、初始化工作簿、导入数据、运行状态、销毁连接、工作簿状态、
  跨 atom 状态转换、可见窗口与 Rust 命令。
- React 负责共享视图、挂载 effect、DOM 事件、焦点、pointer capture 和滚动事件适配。
- React 源码不使用 `useState/useReducer`，也不在本包内声明工作簿 atom。
- Vite 的 `?worker` 语法只存在于共享 `WorkbookRuntimeProvider`；所有 demo 共用它。

普通单元格提交只走一次 `cell.setInput` Worker RPC，结果包含严格 ACK 和同一修订版投影。提交期间
如果用户滚动，独立的滚动投影优先，旧窗口的编辑投影不会覆盖新窗口。
UI Core 不再用 JavaScript 判断输入是数字还是公式，只把原字符串交给 Rust `set_cell_input`。
Rust 输入解析也供外部剪贴板复用；百分比输入的数值与格式在同一条命令内完成，不再追加格式 RPC。

## 撤销、重做与最近操作

- 工具栏 `Undo` / `Redo`；网格中支持 `⌘/Ctrl+Z`、`⌘/Ctrl+Shift+Z`、`Ctrl+Y`。
- `Recent operations` 显示操作名称、工作表、范围及已撤销状态；Escape 关闭并还原按钮焦点。
- 当前覆盖单格输入、格式、清除内容/格式/全部、行高/列宽/恢复默认尺寸、粘贴、同表剪切及工作表管理。
- 历史由 Rust 保存，最多 50 步及约 32 MiB 估算预算；不跨刷新持久化。初始化数据不计入历史。
- 修改 E2 后切换 Summary，再撤销，可看到公式回到原值，当前工作表不会跳回 Sales Orders。
- 复制、切表保留历史；粘贴、创建/改名/删除/移动工作表均记入同一 Rust 历史栈。
  新修改会丢弃重做分支，无变化的提交和失败操作不会。
- 结构撤销尽量保留当前表；撤销新增导致当前表消失时，切到相邻表 A1。恢复表保留原数据、格式和画布尺寸。
  结构撤销/重做会使旧剪贴板失效，粘贴时提示重新复制；不会悄悄改成往其他表粘贴。
- 普通粘贴、选择性模式、列宽、转置、跳过空白、平铺、加减乘除均可撤销；同表剪切的一步撤销会恢复源格、
  目标原值和被改写的引用公式。重做不读取系统剪贴板，旧剪切仍不能再次粘贴。
- 编辑框里的撤销交给浏览器处理，不应触发工作簿撤销；先提交或取消草稿再使用工具栏历史。
