# 高级筛选

完整“筛选条件”面板支持两层组合：组内所有条件按 AND（且）匹配，任意一个组按 OR（或）匹配即可显示该行。可以添加或移除组、编辑组内条件。同组可多次判断同一列，例如同时设置两个数值边界。最多 8 组，每组 8 个条件，共 32 个条件；不能提交空组。

旧工作簿的平面条件继续按 AND 读取。打开已有分组筛选的列按钮会显示完整分组面板，以便保留其余 OR 分支。普通工作表、指定范围与每张 Table 的筛选各自保存条件与隐藏快照；Table 表头、汇总行不参与数据筛选。手动隐藏不因筛选而改变。

“选择值”中的“全选搜索匹配项”选择当前搜索的全部候选，不局限于当前页。“取消所有搜索匹配项”只取消当前搜索匹配的值，其它选择保留。切页保留选择；修改搜索文字不改变选择，也不会应用筛选。原来的“选择当前页”继续只选择这一页。

完整搜索由原生引擎一次查询，最多扫描 50,000 个谓词单元格。一个选择最多包含 1,000 个不同值、文本与条目开销合计 1 MiB。超出预算时明确拒绝，保留已有选择；请缩小搜索或筛选范围。不会截取部分结果后显示“全选”。

只有“应用筛选”提交一次原生历史事务。添加组、浏览或搜索候选不写工作簿。修改单元格不会自动重扫筛选；使用“重新应用筛选”更新隐藏快照。撤销、重做与文件恢复回放原快照。受保护工作表拒绝筛选变更，面板保留草稿与错误，允许取消或改正。

这项能力不是 Office 的完整高级筛选条件区域，也不支持任意嵌套条件树或把筛选结果复制到其它区域。
