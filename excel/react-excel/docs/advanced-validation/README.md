# 高级数据验证

在工具栏打开「数据验证」，选择「自定义公式」，输入返回 TRUE 的公式。相对引用以「应用于」左上角为锚点；例如 D45:D46 的 `=D45>0` 会分别检查 D45 与 D46。使用 `$` 固定行列，跨表引用采用普通 Excel 公式语法。

「选中时显示输入提示」将标题及正文保存在原生验证规则中。选择单元格时显示提示，读取本身不修改内容或历史。

Stop 拒绝不满足规则的原生输入，保留当前草稿并显示错误文本。Warning 与 Information 先拒绝写入，再要求用户明确继续或取消；继续重新走原生完整验证，Stop、保护及 Table 约束始终有效。取消保留草稿，接受一次输入只有一条历史。批量粘贴与填充对整个操作确认，任何 Stop 失败都整体回滚。

空白策略由「忽略空白单元格」控制。未勾选时，自定义公式实际判断空白候选值，允许例如 `=LEN(D45)=0`。公式错误、文本结果及数组条件不当作 TRUE。

标题最多 32 个 Unicode 字符，提示正文最多 255 个字符；内容按纯文本显示。规则、提示、错误级别沿现有工作簿文件及规则历史保存。旧文件缺少高级字段时沿默认 Stop 语义读取。

实现路径是 React DOM → `runNativeDataValidationAtom` / 既有编辑、粘贴、填充命令 → Rust Worker/WASM → 原生验证及历史 → 返回投影。UI Core 仅保留表单与明确确认的原操作参数；React 不解析公式或保存工作簿数据镜像。
