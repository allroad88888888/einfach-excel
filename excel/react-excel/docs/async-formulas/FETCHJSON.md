# FETCHJSON（项目扩展）

`=FETCHJSON(url,pointer?)` 是可信应用安装的异步 JSON 扩展，不是 Office 内置函数。
在公式栏输入同源 HTTP(S) 地址，可选第二参数使用 RFC 6901 JSON Pointer：

```text
=FETCHJSON("/demo/async-formulas/result.json","/price")
=FETCHJSON("/demo/async-formulas/result.json","/matrix")
```

空 Pointer 选择整个 JSON。`/a~1b/~0key/0` 表示属性 `a/b` 下 `~key` 数组的第一个元素。
响应须声明 JSON 媒体类型；选中的结果只能是标量或非空矩形标量数组，数组由 Rust 原生动态数组机制溢出。
JSON 的 `"#N/A"`、`"#VALUE!"`、`"#BUSY!"` 等字符串按字面文本保留，数组元素同样处理，不冒充引擎错误。

函数先显示 `#BUSY!`，实际请求完成后通过原生依赖传播更新本表、跨表公式及数组。
HTTP 拒绝、网络错误或超时显示 `#N/A`；参数、Pointer、JSON、结果结构或预算错误显示 `#VALUE!`。
现有 Recalculate 可重试当前计算范围所观察的失败调用；成功值与正在请求的相同参数保留原生缓存。
多个公式使用相同函数名与相同参数只产生一次原生调用，不新增内容历史。

只接受同源 HTTP(S) URL，拒绝账号密码、跨源、脚本、文件地址；请求不发送凭据、不跟随重定向。
预算为每次请求 5 秒、响应 1 MiB、4 个并发、最多 128 个排队调用、结果 4096 个单元格、JSON 最深 32 层及 20000 个节点。
排队预算超额的调用明确结算为 `#VALUE!`，可在队列释放后使用原重算入口重试。

文件只存公式，不存请求结果、provider 或 JavaScript。打开文件后由可信应用代码重新安装同源扩展。
`FETCHJSON` 已被可信 provider 占用；自定义表达式注册或文件内同名定义会明确拒绝。
本扩展目前没有 Office 原生函数目录元数据；使用公式栏手填参数，参数表单及原生补全不声称支持本扩展。
异步结算只改变原生计算状态；不覆盖用户新值、不绕过编辑保护、不添加 Undo 条目、不移动焦点。
已存在的受保护公式仍正常计算。筛选继续保持显式快照，结算后用原 Reapply 更新；验证和条件格式沿用原生错误语义。
