## 本批：粘贴组合

本批功能为除法、组合选项面板、仅列宽，均沿用一次 `clipboard.paste` 和原生历史。
除法目标在左，除以零返回可撤销的 `#DIV/0!`；公式依赖继续交给 Rust 计算。
`paste-special-panel.ts` 只持有 UI 选项与固定目标，忙碌/错误复用原剪贴板状态；
React 面板只处理 DOM、焦点与事件。取消/成功复位，失败可重试，权限等待期间禁止重复操作。
本轮修正异步 atom 命令等权限完成才通知视图的问题，没有另加 React busy 状态或业务生命周期。
Rust 快照冻结源列宽（包含默认值），`clipboard_column_widths.rs` 只更新目标列属性，
不写单格宽高，不改值/格式/行高，不额外计算公式；一条历史支持撤销/重做。
原响应携带完整目标列宽，同次合并屏幕外尺寸，未增加刷新 RPC。
仅列宽不兼容运算、转置、跳过空白、剪切及外部 TSV；受保护表需先解除保护。
