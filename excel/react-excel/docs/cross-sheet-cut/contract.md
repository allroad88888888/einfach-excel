# 跨表剪切

同一工作簿先 Cut，切换工作表，再 Paste；源区域在粘贴成功时才清空。值、公式、有效单元格格式与已有剪贴板携带的超链接一起移动，列宽和行高不移动。一次 Undo/Redo 同时恢复源、目标及其它表实际改写的依赖公式。

原生公式规则：

- 单格及完整静态 A1 范围引用随被剪单元格移动，保留 `$` 标记。源表、目标表及第三表的静态引用均覆盖。
- 移出公式内未移动的本地 A1 引用补上原表名；已有其它表引用保留原身份。含空格或单引号的表名由原生公式 renderer 转义。
- 部分范围移动原子拒绝；受影响的动态范围或 OFFSET 无法证明完整包含时也拒绝，避免只平移端点改变实际区域。
- 无关动态范围不阻止操作。INDIRECT 的文本地址沿既有语义保留原字符串，不做字符串替换。无参 ROW/COLUMN 等位置函数在新位置正常求值。

跨表源或目标含合并单元格、Excel Table 时本版明确拒绝；同表原有政策继续生效。数组结果、筛选源、特殊粘贴模式、输入验证及保护沿原有边界检查。源、目标、实际依赖公式和边框邻格均由 Rust 检查当前权限。Stop 不能被继续确认绕过；Warning/Information 沿已有确认入口重试同一快照。

源剪切区域与当前有效的原生命名范围完整或部分相交时，本版也明确原子拒绝。命名范围不能留在被清空的源格而使依赖公式静默错算；请通过名称管理器修改或删除该名称后重试同一剪切快照。检查使用稳定工作表身份解析后的元数据，重命名、重排仍正确；已失效定义不误绑定同名新表。无关命名范围、值或表达式名称、LET/LAMBDA 局部名称不阻止移动。

失败不清源、不留下半写工作表、不消耗已确认快照或 redo。切换标签只改变 UI 位置；新复制、原生源内容/格式/链接变化、工作簿替换及既有结构身份规则继续保护快照。浏览器拒绝剪贴板写入时丢弃暂存 cut，之前的正式剪贴板仍可用。

调用链仍是原有 React 剪贴板事件或工具栏 → `runSystemClipboardAtom` → Worker `clipboard.paste` → `WasmWorkbook.paste_clipboard` → Rust `cross_sheet_cut` → 一次投影。Rust 保存唯一原生快照、规划和历史；Core 只传文本、token、目的选区及选项；React 无需新增组件或状态层。

专项验收见 `e2e/cross-sheet-cut/`，FEATURES 稳定 ID 为 XSCUT-001 至 XSCUT-008；双语 1280/390 截图用例独立在 language-layout.spec.ts。浏览器及 WASM 合流验收结果由集成报告提供。
