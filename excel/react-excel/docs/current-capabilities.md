# 当前能力与操作说明

工作簿启动后会向 Rust 引擎导入 1,000 条销售订单记录。界面按实际尺寸与隐藏状态渲染可见窗口，
不会一次挂载整张工作表。Sales Orders 原有 66 组合并样例仍在默认页面（如 A21:C21）；演示合并会覆盖部分原始订单值。
筛选、排序、查找等完整订单回归使用测试专用数据入口，不改变默认演示。

目前支持：

- 宿主通过 [`createWorkbookApi(store)`](package/workbook-api.md) 显式读写格式、清除/平移区域、
  行列结构与尺寸、冻结合并、排序筛选、规则、工作表管理、查找替换和统一撤销重做；
  同一入口控制选区/滚动/缩放/编辑，提供修改前取消、修改后与交互订阅；
- 功能区布局：分类标签独占一行，下方按组排两行工具（组间竖线分隔，粘贴为跨两行的大按钮）；
  历史组常驻最前，开始页含剪贴板、字体、对齐、数字、样式，其余工具在各自分类；放不下时末尾的组
  整组收进 `More tools`（⋯ 更多），面板按组分段带组标题，执行按钮或菜单命令／Escape／点击外部／切换分类收起；
  窄屏面板自动换行；更多按钮支持 ↓／↑ 进入首项／末项，Tab／Shift+Tab 离开后收起；
  设置选择框支持连续键盘调整，对话框保留原入口，错误提示会自动展开；
- `ui.ribbon.hidden` 按稳定 ID 隐藏按钮，`ui.rowHeaderWidth / columnHeaderHeight` 调整标题尺寸；
  配置可热更新，Canvas 支持单格 before/after 绘制钩子；
- 单元格单选和拖拽框选；Shift 点击或拖拽沿用原起点，连续点击可缩选或反向扩选；
  Shift 加方向键／PageUp／PageDown 扩选，Shift 点击行号／列名扩选整行／整列；
- Ctrl/⌘ 点击或拖拽追加非连续区域；重复矩形激活已有区、部分重叠保留，Escape 结束拖动并只留主区；
- 新增空白工作表、切换标签、重命名、删除与左右移动（含静态跨表公式引用随动）；
  Ctrl/⌘ 点击或 Shift 点击标签、右键 `Select all sheets`／`Ungroup sheets` 可分组工作表，分组期间输入、设置格式、清除选区同步写入组内全部可见表并记为一步撤销；
- 点击行号选择整行、点击列名选择整列、点击左上角选择整表；
- 设置所选行的行高、所选列的列宽、恢复所选行列的默认尺寸；
- 隐藏所选行、隐藏所选列、恢复选中范围或整表的隐藏行列；
- 视图选项：按工作表隐藏网格线、行列标题（随文件与 XLSX 保存，不进撤销历史），隐藏公式栏（仅本次挂载）；
- 清除选区内容（也支持 Delete）、清除格式、全部清除；
- 系统剪贴板复制、同表／跨表剪切、矩形粘贴（工具栏与 Ctrl/⌘+C、X、V）；
- `Copy as`：复制为纯文本、Markdown、HTML 表格；
- 仅粘贴值、仅粘贴格式，以及将复制内容重复铺满矩形选区；
- 转置粘贴、跳过空白、粘贴值及格式（工具栏 `Paste options` 下拉菜单）；
- 粘贴加、减、乘、除：批量运算保留公式依赖，可一步撤销/重做；
- `Paste special` 组合粘贴选项；仅粘贴列宽，可恢复目标的默认列宽；
- 仅公式、公式及数字格式、值及数字格式（同一个下拉菜单）；
- 仅粘贴备注、仅粘贴数据验证（自定义公式的相对引用随粘贴位置平移；需复制本工作簿内的连续区域）；
- 向下／向右填充（`Fill` 菜单或网格中的 Ctrl/⌘+D、R），支持原生撤销重做；
- 查找替换支持按当前表／整簿／原选区、通配符、区分大小写、整格匹配、公式或显示值查找，并支持展开「格式条件」按粗体、斜体、下划线、填充色、文字颜色与数字格式类别查找或替换格式（支持「从活动格提取」一键采样，仅按格式查找可定位已设样式的空白格，替换格式保留原公式与值且单步撤销）。
- 从首行滚动到最后一条记录；
- 双击单元格、按 F2 或直接打字进入编辑；未编辑时 Enter 向下移动选区；
- 在名称框输入单元格地址，跳转选区和可见窗口；
- 在公式栏直接修改活动单元格；
- 工具栏 `Insert function` 按名称／分类浏览当前 Rust 构建的全部内置函数，插入公式栏草稿；
- 格内与公式栏自动补全共用原生目录，完全匹配优先，候选最多 8 项；
- 按 Enter 或失焦后，通过一次 Rust command 同时写入并取得当前可见投影；
- 按 Escape 取消编辑，不产生写入；
- 公式栏 Enter 保存或 Escape 取消后回到网格，可直接用方向键／撤销快捷键继续操作；
  校验拒绝时保留草稿及输入焦点，慢响应不会抢走已移到其它控件的焦点；
- 校验拒绝后双击其它格不会覆盖失败草稿；先修正提交或 Escape 取消，再编辑下一格；
- 失焦保存期间双击下一格，会等这一笔写入确认后进入编辑；等待时改选别处或进入其它控件，
  不再打开过期的编辑器，不重复写入；
- 原始数值编辑（公式栏和格内编辑不使用经过货币、百分比或 General 舍入的显示文本）；
- 前导 `'` 强制文本、TRUE/FALSE 布尔值、百分比输入，由 Rust 统一识别；
- 两种编辑入口均支持 Alt+Enter 在光标处换行，Enter 提交；输入法组合确认键不触发提交或取消；
- 通过工具栏设置字体、颜色、边框、对齐、旋转、缩进等单元格格式；开始 → 样式组的 `Cell styles and themes`（`format.cell-styles`）内置 28 项 Excel 风格单元格样式（好/差/适中/常规、数据与模型、标题与汇总、主题强调色及 20% 浅色）与 5 套工作簿主题（`Office`/`Facet`/`Integral`/`Slate`/`Warm`），切换主题为当前会话调色板偏好（不进入撤销历史或文件元数据），实时联动样式库及填充/文字颜色面板中的「主题颜色」行，点击应用时单次原子写入具体填充/字体/边框并支持单步撤销与原生文件保留；
- 百分比、货币、会计专用、千分位、日期格式，以及增加小数位、减少小数位、恢复常规格式；数字格式对话框的 Custom 类别可输入 Excel 格式代码（四节、颜色、条件、字面量、`_`／`*` 填充），预览、网格与 Canvas 同用 Rust 显示结果，无效代码原地提示。
- 会计专用格式支持币种符号或空符号、0–15位小数：符号靠左、数值靠右、负数括号、零为破折号；预览与自动列宽读取同一份 Rust 文本与留白。原生文件及 XLSX（内置41–44、自定义币种）往返保留会计类别；Summary 的 A19:C19 是正/负/零示例，Sales Orders 的 O19/P19 是自定义颜色与填充示例。
- 数字格式对话框的 Special 类别提供 English (United States) 的 ZIP、ZIP+4、Phone、SSN，以及 Chinese (China) 的六位邮编。预设仅改变数值显示，保留公式和已有文本；前导零、负号、舍入与超长数字均由 Rust 格式引擎处理，不清洗号码。区域切换只改草稿；原生和 XLSX 往返可回读类别、区域及类型。Summary A23:E23 为五种预设示例。

设置数字格式不改已有数值或公式；文本格式会影响之后的新输入。小数位按钮范围为 0–15 位，沿用活动单元格的
数字格式应用到选区；恢复常规格式不会清除字体、颜色或边框。可在名称框跳转到 `O4`
（初始 `10.00%`）、`P3`（初始粗体 `$125`，原值 `125.02`）和 `G9`（初始 `2,632.00`）测试。

`Insert function` 的目录来自当前 Rust/WASM 编译产物：lite 499 项，full 502 项（增加三项 REGEX）。
这些数量包括别名，不代表与 Office 所有函数完全兼容。搜索 `XLOOKUP` 后点 `Insert draft`，
会在活动格生成 `=XLOOKUP(` 草稿；填写参数后 Enter 或失焦提交，Escape 取消。
搜索／分类／取消都不改数据，已有编辑草稿时入口禁用。当前构件的全部内置函数都有原生中英文帮助，
函数选择器、格内与公式栏展示签名、参数、可选／重复组、示例及实现限制。
选择有可用原生签名的函数后，`Fill arguments` 打开[参数表单](formula-arguments/README.md)，
支持必填／可选空位、重复组与固定尾参；`Create formula draft` 只生成原公式栏草稿，Enter 才提交，
Cancel／Escape 不写入。地址和表达式直接填写，本版不含模态内网格拾取或另一套结果预览。
目录会注明 `IMAGE` 当前返回图片元数据文本、`HYPERLINK` 当前返回显示文本、`TRANSLATE` 当前为字符替换。
公式 `HYPERLINK()` 尚不生成可点击链接；手动超链接使用下面的独立入口。
Formulas 中的 `Custom formulas` 可注册、替换和删除工作簿级参数表达式，沿 Rust 的 LAMBDA 求值；
保存的定义也进入函数选择器与补全，可在任意工作表调用。不提供宿主 JavaScript 回调或文件内脚本执行入口。

工具栏 `Hyperlink`（↗）或网格 Ctrl/⌘+K 支持插入、修改地址／显示文字、移除链接。
Sales Orders `B2`、`B3` 是原生种子示例。普通单击选格，Ctrl/⌘+单击在新标签页打开；
弹窗也提供可用键盘操作的打开链接入口。只接受绝对 HTTP／HTTPS 地址，拒绝脚本、文件路径和含账号密码的地址。
保持显示文字不变时保留原数值／公式；修改文字会替换为普通文本；移除链接保留内容及格式。
Table 单元格的文字须经原有编辑入口修改，此弹窗可以独立修改或移除其链接，避免绕过表头／计算列规则。
每次修改一条原生历史；普通复制／剪切携带链接，仅粘贴值／格式／公式及粘贴运算保留目标链接。
清除内容／格式保留链接，全部清除移除链接；插删行列及既有下载／打开 `.einfach.json` 跟随原生元数据。
不含内部工作表跳转、邮件链接，也不加入本地自动保存。

单元格富文本已接入：文字分段可设字体、字号、颜色和粗斜体／下划线／删除线，
具有原生撤销、普通编辑保留样式、复制填充、结构移动与工作表复制，DOM 与 Canvas 共用投影；
原生文件和 XLSX 共享／内联字符串保留分段。可选文字格式插件提供局部上标／下标，
同效果再次点击写入显式正常基线，重置格式恢复整格继承；保存时产生一次原生历史。
HTML 复制按文本段输出经过转义与 CSS 白名单处理的字形样式；纯文本仍保留原文字。
不安装插件时仍显示和保存已有格式；Table 数据格、表头及空表首行同样支持富文本编辑。

文字格式插件还提供“缩小字体填充”。开启时同一事务关闭自动换行，开启换行时同一事务关闭缩小；
关闭只改自身，撤销、重做与重复沿共享历史。列宽增大时恢复原显示字号，短文字不放大，原字号与内容不变。
DOM、Canvas、PNG 支持普通文本、公式结果、混合字号及会计／自定义格式的填充与占位；AutoFit 按自然宽度计算。
硬换行、竖排及启用换行的文字不缩小。外来文件的双真标志保留，显示优先换行；行列继承与显式关闭
通过原生文件、XLSX 保留。不安装插件时仍能显示、保存这些格式。

可选 `cell-appearance` 插件在边框面板提供下斜线、上斜线、双斜线、仅清除斜线，
复用线型、颜色、草稿与一次原生事务；卸载时保留已打开草稿，重装恢复标签。
斜线预设保留四边；物理边框预设保留斜线；“无边框”及默认快捷全边框关闭时清除全部六边。
DOM、Canvas、PNG 按完整单元格或合并格尺寸绘制，冻结与隐藏轴不重起路径，双线按法向平移。
复制、格式刷、填充、清除、重复、保护与历史沿原有命令；原值、字号与尺寸不变。
原生文件与单元格 XLSX 样式保留两方向；同时启用时必须同线型同颜色，未知 XLSX 线型明确报告。
边框编辑仍限单一连续范围及 100,000 格；XLSX 行列斜线沿已有损失报告，不承诺轴样式保真。
Summary `F15:F17` 是原生样例，无插件也可显示和保存。详见[插件说明](../../../plugins/plugin-cell-appearance/README.md)。

同一外观插件提供全部 17 种图案及图案颜色／底色输入。面板草稿属于插件 `/core`，
Apply 复用公开格式命令和一次 Rust 事务；取消不写，失败保留草稿，旧连接或旧选区不能接收提交。
固色入口清除图案，“无填充”同时清除图案与底色；背景条件格式临时遮盖图案，停止命中恢复。
DOM/Canvas/PNG 共用 8 像素逻辑图块。Summary `H15:H17` 提供有文字、空白格示例，无插件仍显示和保存。
原生及 XLSX 支持单格、稀疏整行／整列图案与显式清除；XLSX 图案前景色和底色分别保存。
XLSX 无法完整表达的独立跨层继承明确报告：单格部分覆盖保留当前外观，行列交叉不展开成整表。
外观插件也提供线性与矩形渐变。类型切换保留本次编辑的角度、矩形边界与所有色标，应用只提交当前类型。
DOM、Canvas 与 PNG 按完整单元格或合并格绘制，Summary `H11:H13` 提供示例。
原生格式和 XLSX 保留渐变参数、色标顺序及重复位置。XLSX 会报告空色标、无法表示的独立底色、
未知填充及不支持的非固色条件格式。

可选 `data-sort` 插件提供填充色和字体色排序。纯色、无填充与自动字体色可以置顶或置底，
同列可重复作为多个优先级。Rust 使用移动前的条件格式、表格样式、数字格式段色及原生样式。
条件格式按排序后的单元格重新求值，原生与 XLSX 文件保存结果行序。Summary `A75:B78` 提供示例。
“图标排序”通过同一插件匹配条件格式实际显示的图标或无图标，并可混合颜色和普通值级别。
图标集与最终显示索引一起比较，反转顺序和仅显示图标也生效。Summary `H75:H79` 提供示例。

同一插件的“从左到右排序”以行号为键，在所选矩形内移动列记录。值、填充色、字体色和图标可以组合成多个级别，
外观条件可指定左置或右置。隐藏列留在原位置，列宽与行列样式归原坐标，公式源码和单元格格式随记录移动。
表格先转换为普通区域，活动筛选先清除后再横向排序。撤销与重做沿用原生历史。
原生与 XLSX 文件保留排好的列序。Summary `F60:H61` 可按第 60 行的键试用，默认隐藏的 G 列留位。

宿主可高亮区域、查询实际可见性、打开函数参数面板，并嵌套暂停绘制或计算。
见 [Workbook API](package/workbook-api.md)。本轮完成编译与冒烟检查，新增单测留待统一补充。
功能源码集中在各层 `hyperlink/`，通用网格、工具栏及文件格式只保留必要接线。

`Recalculate` 菜单可选当前工作表或整个工作簿；Rust 强制重算已有公式，当前表的跨表下游也会更新，
无关表只有选择整个工作簿才强制重算。不重写公式、不增加撤销记录；编辑草稿期间禁用。
Summary `D62` 的 `=RAND()` 与 `E62` 的 `=D62*2` 是原生示例，点击后可观察新随机数与下游。
`Show formulas`（`=` 按钮）显示／隐藏当前表公式，普通、冻结、合并区域一致；强制文本不被识别成公式。
这是每张表的临时显示偏好，新建／打开工作簿后清空；不改数字格式、数据、列宽、剪贴板或撤销记录。
工具栏支持自动／手动计算模式，F9 重算工作簿，Shift+F9 重算当前表。
`Iterative calculation` 可启用循环迭代，并设置最大次数与收敛误差；模式与迭代参数保存到原生 JSON 和 XLSX。
三维引用如 `=SUM(Sheet1:Sheet3!A1)` 聚合连续工作表，源数据变更后沿 Rust 依赖重算。
迭代依赖收集覆盖三维引用与工作表级命名公式。

公式审核工具栏提供 `Trace Precedents`、`Trace Dependents` 与 `Remove Arrows`，
覆盖普通引用、三维引用及带工作表前缀的命名公式；跨表箭头提供目标表定位入口。
`Evaluate Formula` 显示当前求值子表达式，支持逐步求值、步入、步出、重新开始和关闭。
`Watch Window` 可添加单元格监视，随源数据变化更新结果，点击监视项可跨表定位，支持删除监视项。
这些查看操作不改写公式或增加撤销记录。
本版 `Recalculate` 对所选表相关的失败异步调用重试，成功／正在执行的 memo 保留；共享同一请求的消费者随原生依赖更新。
独立 `?demo=async-formulas` 展示项目扩展 [FETCHJSON](async-formulas/FETCHJSON.md)：同源JSON请求、
`#BUSY!`、标量／矩形数组及跨表依赖。仅可信应用安装 provider，文件只保存公式数据，不保存或执行脚本。

外部 TSV 支持多行、多列、引号内换行、空格子、数字、布尔值和公式，不覆盖目标格式。
权限失败会在底部提示；工具栏读取权限被拒绝时，可在网格按 Ctrl/⌘+V。编辑器打开时
剪贴板按钮禁用，输入框内仍使用原生文字复制粘贴。复制 `A2` 可验证粗体，复制 `G2` 到 `G3`
可验证公式平移，剪切 `E2` 到 `E4` 可验证 `G2` 的引用跟随，无需添加另一份测试数据。

`Paste values only` 保留目标格式，公式转为复制时的计算结果，不使用经过显示格式舍入的文本。
例如复制 `P3` 到 `B3`，仅粘贴值会得到 `125.02`，而不是 `125`。
`Paste formatting only` 只写格式，不改目标数值或公式；复制 `P3` 的格式到 `G9` 可验证。
外部文本的仅值粘贴不会执行公式；仅格式粘贴要求当前工作簿的内部复制快照。

单格目标会展开为复制内容的尺寸；较大选区的行列数必须分别是源区域的整数倍，否则整次拒绝。
例如复制 `A2:C2`，选择 `A10:F11` 后粘贴，会重复填满选区，公式按各目标位置平移。
剪切不支持重复填充或选择性粘贴，拒绝时仍保留源格。
`Paste options` 提供以下一次性操作，选择后立即粘贴，不改变下一次普通粘贴的行为：

- `Paste and add / subtract / multiply / divide` 分别计算「目标 + / − / × / ÷ 复制内容」。复制 `E4`（3）到
  `E10`（9）可得到 12 / 6 / 27 / 3。内部复制同时带源格式，外部 TSV 保留目标格式，不复制行高/列宽。
  公式保留为组合表达式，源公式先平移引用；复制 `G2` 到 `G3` 做加法后，修改 `E3` 仍会重算。
  空白按 0、布尔按 1/0、数字文字按数字运算；非数字文字产生 `#VALUE!`，溢出产生 `#NUM!`，可撤销恢复。
  除以 0 产生 `#DIV/0!`，同样可以撤销。
- `Paste transposed` 交换源区域的行列，数值与格式一起转置；公式按各源格到目标格的偏移调整，
  绝对引用保持不变。复制 `A2:C3` 到 `A10` 会得到 3 行、2 列，也可以按转置后的尺寸平铺。
- `Paste skipping blanks` 保留空白源格对应的目标内容与格式；`0`、`false`、空字符串和
  返回空字符串的公式不是空格。先清空 `A2` 内容，再复制 `A2:B2` 到 `A10` 可测试。
- `Paste values and formatting` 保留复制时的原始数值/计算结果及样式，不保留公式。
  复制 `P3` 到 `B3` 仍显示粗体 `$125`，清除目标格式后可看到原始值 `125.02`。
- `Paste formulas only` 保留公式并平移相对引用，不覆盖目标格式；混合区域里的常量仍会复制，
  不是只筛选公式格。可复制 `G2` 到 `G3`，目标不会被源格的 Georgia 字体覆盖。
- `Paste formulas and number formats` 保留公式，同时只复制数字格式；不改目标字体、颜色等。
  复制 `G9` 到 `G10`，显示 `1,341.00`，公式变为 `E10*F10`，修改 `E10` 仍会重算。
- `Paste values and number formats` 把公式变成复制时的计算结果，只携带数字格式。
  复制 `P3` 到 `B2` 显示 `$125`，保留 B2 原有斜体、不带源粗体；原始值仍是 `125.02`。

`Paste special` 面板可组合内容模式、加减乘除、转置和跳过空白，一次确认只产生一条粘贴历史。
失败保留选项以便重试，取消或成功后恢复默认；等待权限时控件禁用，不允许重复提交。
`Column widths only` 只修改目标列属性，不改内容、格式或行高；只接受本工作簿的复制快照，
不能配合运算、转置、跳过空白或剪切，受保护的工作表需先解除保护。
例如复制 Summary 的 `A1:B2` 到 Sales Orders 的 `B4`，B 列变为 200px，C 列恢复默认宽度；
列宽在复制时冻结，选多列时按源列数平铺，可撤销/重做，屏幕外列同步更新。

外部 TSV 支持转置、跳过空白、公式粘贴；外部公式按原文引用，不凭空猜测源坐标。
它没有源样式，因此“值及格式”和两种“数字格式”粘贴会明确拒绝。
剪切不接受以上特殊粘贴操作，拒绝后可以继续普通粘贴。部分公式范围移动、多区域剪切、
Copy As 图片及完整合并/筛选导出、批注粘贴等能力仍待接入。
单次操作上限为 1,048,576 格、文本 16 MiB，越过当前工作表边界会拒绝。

`Copy as` 从 Rust 读取完整选区，不受屏幕可见窗口限制；它复制显示结果，不保存公式：

- `Copy as plain text`：输出 TSV，去掉样式，格内换行和制表符折为一个空格。`P3` 得到 `$125`；
  需要原始值 `125.02` 时用普通复制加“仅粘贴值”，不要用显示文本导出。
- `Copy as Markdown`：首行为表头，保留粗体/斜体，换行转为 `<br>`，特殊字符按文本转义。
  选中 `A2:C3` 可看到 Markdown 表格；不保留颜色等 Markdown 无法表达的样式。
- `Copy as HTML table`：生成带字体、颜色、对齐等基础样式的 HTML 表格，同时提供纯文本版本。
  选中 `A2:F2` 验证原始种子的粗体、斜体、下划线、背景色和文字颜色；`I3` 可验证多行文本。

三种操作共用现有剪贴板反馈，未提交草稿存在时禁用。失败可重新选择同一个选项重试。
导出不改变选区投影、不覆盖原 Rust 剪切快照，也不携带内部 token；粘回本表时按外部文本处理，
不会意外变成移动源格。HTML 格式能否保留取决于接收应用，本表目前不导入外部 HTML 样式。
Copy As 单次上限为 100,000 格、最终文本共 16 MiB，超限拒绝而不是只复制前一部分。
过滤行、合并、列宽行高及 PNG 导出仍需后续接入真实 Rust 投影，不据此宣称完整导出兼容性。

工作表标签与本地操作历史已接入；缩放区域仍主要负责界面展示，持久化版本历史尚未接入。
底部工作表栏采用浅灰分隔标签，当前页白底绿字，整表只读页保持灰色。栏上保留前后切换、
标签与右侧“+”；重命名、左右移动、删除、复制、隐藏等操作集中到标签右键菜单，目标为
右键点击的工作表。双击或 F2 仍在标题原位改名；Shift+F10 或菜单键可打开右键菜单。
编辑来源已与显示文本分开：例如 `P3` 显示 `$125`，进入编辑及公式栏显示的是 `125.02`；
`O4` 显示 `10.00%`，编辑值为 `0.1`。直接 Enter 或失焦不会把显示舍入写回原值。
`I3` 是原始种子里的两行示例 `Noah` / `East team`。格内和公式栏都能用 Alt+Enter 换行，

文本数字、布尔、空值与错误均忽略。没有数值时不高亮；单个数值仅在包含等于时命中。
数值先精确累加再除以计数，最终舍入到有限浮点均值做严格比较，不额外添加近似容差；
