# 自定义公式 / Custom formulas

工具栏的“自定义公式 / Custom formulas”打开原生定义目录。输入函数名、逗号分隔的参数名、公式表达式，点击“注册公式 / Register formula”。例如 `DOUBLE`、`amount`、`=amount*2`，然后在任意工作表输入 `=DOUBLE(E2)`。

从“已保存的公式 / Saved formula”选择定义，可以替换表达式或移除函数。替换、移除会让所有工作表的调用者由 Rust 重新计算；定义操作不写入用户格子。移除后的调用返回 `#NAME?`。Undo/Redo 恢复定义及计算结果，原生工作簿下载/打开保留表达式。

函数名与参数名不区分大小写，原生目录统一为大写。名称以字母或下划线开始，只包含字母、数字、下划线或点，不得与内置函数、现有名称或 Table 冲突，也不能是 A1/R1C1 地址。参数不可重复，每个参数都必须提供：缺少或多余参数返回 `#VALUE!`。零参数定义可以通过 `=MYFUNCTION()` 调用。

表达式支持已有 Rust 内置公式、LET/LAMBDA、数组以及已注册的其他自定义公式。把单元格或范围通过实参传入，定义正文只允许声明的参数及 LET/LAMBDA 局部名称，不接受全局命名区域、直接单元格、范围、跨表或 Table 引用，也不接受 INDIRECT/OFFSET 等隐式读取当前位置的函数。静态递归/相互调用环在保存前拒绝；动态 LAMBDA 递归受原生深度限制并返回 `#NUM!`。注册时拒绝未知函数；已调用的自定义函数后来被移除时，消费者显示原生 `#NAME?`，文件往返保留该错误及定义。最多256个定义、每个64个参数、8192字符表达式。

受保护工作簿不能注册、替换、移除定义，因为重算可影响所有工作表。失败后保留草稿，可以修改或取消；读取期间可以取消，保存期间禁止重复提交和取消。下载文件只保存公式文本，不保存或执行 JavaScript。既有宿主 callback API 保持可用，但不属于文件内的用户定义。
