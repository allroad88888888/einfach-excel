# 定向填充批次

## 三个功能

1. Fill down：以选区第一行为源，复制到后续各行。
2. Fill right：以选区第一列为源，复制到后续各列。
3. 网格 Ctrl/⌘+D、Ctrl/⌘+R：复用菜单 command；输入框、编辑模式、组合键不接管。

## 数据与边界

- 选区同时包含源和目标。值、公式及有效样式复制；Rust 负责相对引用平移，绝对引用不变。
- 空源清除目标内容；默认格式也是覆盖，不能漏出目标行列的继承样式。
- 不复制行高列宽；复制的大字按原规则撑高目标行，高度仍只属于 rowStyle。
- 隐藏格参与填充。单次最多 1,048,576 格；单行向下、单列向右、非法坐标直接拒绝。
- 非连续多区、受保护工作表、合并选区明确拒绝；原生预检拒绝目标 spill，不产生部分修改。
- 一次操作只有一个原生历史步骤。既有系统剪贴板快照不被填充覆盖。
- 不包含拖拽填充柄、序列面板、日期序列，不把原编号 12 标为全部完成。

## 最短链路

`FillTools / 网格按键 → fillSelectionAtom → range.fill → Rust apply_auto_fill → 返回投影`

- React 只读取反馈、发送方向；键盘解释器负责识别方向，不复制另一套写入逻辑。
- UI Core 读取当前选区，检查编辑／保护状态，请求一次写入并发布返回结果。
- Worker 只转换现有原生范围字段，在现有历史分组里调用 Rust。
- Rust 拥有填充计划、公式、数据、样式及历史；JS 没有逐格填充或工作簿镜像。
- 同一响应携带全目标尺寸，离屏大字行高也能更新几何缓存，不额外请求刷新。
