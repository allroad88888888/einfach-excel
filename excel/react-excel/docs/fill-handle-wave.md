# 填充柄批次

## 三个功能

1. 选区右下角填充柄：向上、下、左、右拖出目标，松手执行一次原生填充。
2. 自动延续单行／单列里的等差数字或文本编号；由 Rust 读取当前源样本并推断。
3. Ctrl/⌘ 强制循环复制；拖动中可切换，松手时决定模式。

拖动只更新预览，源选区不动；成功后选中完整范围。Escape、pointercancel、捕获丢失、
窗口失焦、切表或选区变化取消拖动，不写数据。只点击填充柄不应填充相邻格。
支持四边自动滚动与冻结区坐标，隐藏行列仍参与原生写入；不为每个冻结分区创建填充柄。

## 归属与边界

`FillHandle → dragFillHandleAtom → fillSelectionAtom → 一次 range.fill → Rust → 投影`

- React：指针捕获、DOM 命中、预览坐标、焦点；复用选区拖拽的自动滚动 hook。
- UI Core：源与目标范围、方向和复制开关；复用既有 command 的保护、历史及投影发布。
- Worker：显式源范围与四方向的传输，历史快照只覆盖目标，不读取样本或计算规律。
- Rust：复用现有 inference 与填充预检；自动模式试验源样本，无法识别就复制。
  已识别的序列若在目标生成时溢出，必须拒绝，不降级为复制掩盖错误。

单格、公式、常量、无规律样本、二维源矩形默认复制，公式相对引用仍由 Rust 平移。
本批不补日期、星期／月份、自定义列表、多行列独立序列或双击自动填到相邻数据尾部。
原计划 #12 不记为全部完成；合并、spill、保护等拒绝路径沿用原生边界。

- Summary `D71` 向右拖动复制带下划线的 Fill me；`B71` 向下拖动复制相对公式。

这些样本复用既有 page/demo 原始 Rust 种子，不在 grid 中按坐标伪造数据或样式。
