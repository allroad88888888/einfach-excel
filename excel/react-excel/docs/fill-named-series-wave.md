# 名称序列批次

本批三个功能：星期名称、月份名称、自定义顺序列表。实现已随 `d8ecb165` 提交；2026-09-09 完成全量验收。

## 操作与范围

选择单行或单列的「源样本 + 目标」，打开 `Series…`，选择类别，确认样本数量后应用。
一个样本沿列表前进一项；多个样本推断循环步长，源样本必须全部符合规律。
例如 Mon、Wed 延续 Fri、Sun；Mar、Feb 延续 Jan、Dec。源格原文不改，目标使用列表中的名称。

- 星期：英文 Mon…Sun 或 Monday…Sunday；中文 星期一…星期日、周一…周日。
- 月份：英文 Jan…Dec 或 January…December；中文 1月…12月、一月…十二月。
- 自定义：每行一个项目，2–512 项，非空、大小写归一后不能重复，总输入最多 16,384 个 UTF-16 单元。
  当前按英文大小写规则匹配，不提供自定义地区选项。输入边缘空白会去除。

名称作为文本写入，不是日期值，不引入日期纪元、日期显示或工作日计算。
英文源大小写不敏感，生成值使用内置标准写法；例如 fri 保留原文，后续生成 Sat、Sun。
自定义草稿只在当前工作簿会话内保留；没有注册、持久化、排序或跨工作簿列表管理。
星期／月份支持填充柄自动识别，Ctrl/⌘ 仍强制复制；自定义列表当前只通过 Series 面板应用。
日期、其它地区名称、自定义列表拖拽、多行列独立序列、双击自动填充仍留在计划 #12，未记为全部完成。

## 示例

- Summary `A55:A59`：Weekday names，源数量 1，得到 Friday…Tuesday，保持粗体。
- Summary `C55:C59`：Month names，源数量 1，得到 Nov、Dec、Jan、Feb、Mar，保持斜体。
- Summary `E55:E59`：Custom list，填入 Low、Medium、High 三行，保持下划线并循环。
- Summary `A60`、`C60` 是星期五、11月；拖动填充柄即可验证中文名称跨周期。

所有示例仍由 page/demo 的原始数据导入 Rust，不在视图中复制内容或按坐标造样式。

## 最短链路

`FillSeriesTools → configureFillSeriesAtom → fillSelectionAtom → range.fill → Rust → 投影`

- React 只渲染选项与焦点；共享选项清单避免 React 和命令的样本数量要求漂移。
- UI Core 只保存面板草稿、选区与错误，复用既有填充命令、等待反馈与投影发布。
- Worker 传递类别、样本数和用户列表，复用一次历史操作，不读取样本或自行计算名称。
- Rust 从真实源格匹配列表、推断步长，复用原生预检与写入；错误不留下半次更新。

`inference/named.rs` 只负责名称推断，没有新增 backend、注册器或响应式数据副本。
填充仍包含隐藏格、继承有效样式、可一次撤销，不改变已有剪贴板快照。
