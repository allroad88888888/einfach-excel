# 序列填充批次

## 三个功能

1. 数值等差：从至少两个原生数值样本推断固定非零差值，支持整数、小数、负向递减。
2. 文本编号：至少两个编号样本，保留相同的前后缀与数字补零宽度，支持递减和位数增长。
3. 线性趋势：至少三个数值样本，按所有样本拟合最小二乘直线，不把最后一个差值当趋势。

共用 Series 面板：方向为向下／向右，可指定选区前多少格为样本；样本与目标必须在同一行或同一列。
保留源样本不改动，后面至少有一格目标；最大 1,048,576 格的既有原生上限不变。

## 最短链路与归属

`React Series 面板 → 面板 command → fillSelectionAtom → 一次 range.fill → Rust → 返回投影`

- React 只收集选项、管理原生 dialog 的焦点，不持有工作簿数据。
- UI Core 面板 atom 保存目标与草稿，提交复用定向填充 command，忙碌与反馈也共用。
- Worker 只转换范围，传 `infer: true` 和序列类别；不读取样本、不推算步长或斜率。
- Rust 子模块 `auto_fill/inference.rs` 从当前样本得到原生参数，再进入既有完整预检与原子写入。
- WASM 的 `infer` 默认 false；旧显式参数调用继续原有校验。本批不添加第二个 RPC 或 backend 层。
- 一个原生历史步骤，返回同修订版投影及目标行列尺寸；格式仍按样本循环复制，尺寸不随样本复制。

公式样本、非数值样本、不等差数值、编号不一致、零步长／平坦趋势、越界及非有限生成值明确拒绝。
合并选区、目标 spill、受保护工作表、多区仍沿用填充原有约束。隐藏格正常参与，不冒充“仅可见格”。
这不是完整自动填充项完成：填充柄、日期／星期／月份、自定义列表仍保留在后续范围。
日期功能须先解决原生日期基准与格式显示，不以数值序列代替日期能力。
