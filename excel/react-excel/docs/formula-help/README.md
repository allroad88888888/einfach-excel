# 函数参数帮助

函数帮助从当前 Rust/WASM 编译目录读取：lite 为 499 项，full 为 502 项；full 额外包含三个 REGEX 函数。别名按分发表中的实际名称展示，不会把未编译函数当成可用函数。

## 使用

点击工具栏 `ƒx`（Insert function / 插入函数），按名称或分类查找函数。面板显示双语摘要、参数含义、必填/可选标记、重复参数组、示例及已知实现限制。没有参数的函数显示 `PI()`，不会用 `args...` 冒充签名。

选择 Insert draft / 插入草稿只在公式栏放入 `=NAME(`；工作簿不变。确认完整公式后才走既有 Rust 写入与 Undo/Redo。关闭、取消、搜索和浏览帮助均不产生历史或持久数据。

格内编辑和公式栏共用同一帮助视图。高亮根据光标实际参数位置及整个调用的参数数量定位，忽略字符串、嵌套调用、数组和结构化引用内的逗号：

- SUMIFS 反复高亮 `criteria_range` / `criteria` 成对参数，而不是永远停在最后一项。
- LET 的名称/值组可重复，最后的 `calculation` 固定；未完成值参数仍按值高亮。
- MAP 的数组可重复，最后的 `lambda` 固定。
- SWITCH 的 case/result 成对，额外奇数项为默认值；LAMBDA 允许零个形参并保留最终函数体。
- AGGREGATE 的字面功能码 14–19 将最后一项识别为 `k`；1–13 仍是数组。若功能码来自引用或表达式，帮助不执行公式，也不猜测最后一项的角色。

## 数据与准确度边界

`excel-core/src/formula_help/` 的十个领域 TSV 维护原生签名、双语摘要和可执行示例；`parameters.tsv` 复用确有相同语义的参数词汇，`parameters.rs` 处理上下文特例。`?` 表示可选，连续 `*` 参数表示一个重复原型组。帮助只描述当前引擎，不声称与 Office 完全等价。例如 CEILING/FLOOR 实际为单参数舍入，TRANSLATE 是字符替换，IMAGE 不渲染图片，部分范围函数不接受字面数组常量；这些差异在面板中明确显示。

元数据协议为 catalog v2，Core 严格校验每一项；v1 只保留旧宿主兼容，不计作完整帮助。帮助不写入原生文件，也没有结构迁移。原生自定义公式定义投影在内置项之后合并，增删/历史/文件更新沿已有定义 hydrate 路径响应，不另读目录、不执行脚本。

## 验证

原生专项逐个检查实际编译目录、双语参数、示例解析与求值、别名签名、非重复函数的参数数量拒绝边界以及工作簿历史只读性。Core 专项检查严格 v2、绑定连接、旧 v1 兼容、自定义投影合并及真实调用定位。React 专项检查双语呈现、固定后缀高亮和零参数。

`e2e/formula-help/` 提供 16 个持久 Playwright 场景，覆盖 full/lite 构件元数据、499 项真实选择器逐项呈现、1280/390px、中英文、格内/公式栏、取消/搜索恢复/焦点、原生提交历史和下载文件只读性。该任务不运行浏览器或重建 WASM；这些场景由共享验收统一执行。截图输出由测试产物目录管理，未执行之前不宣称视觉验收通过。
