# 冻结窗格批次（三项交互已验收）

三项功能：冻结首行、冻结首列、按当前单元格冻结／取消冻结。三项交互已通过本批验收。
页面保存／打开与刷新恢复仍未接入，不把原生快照能力当作产品持久化完成。

## 当前完成的原生链路

`sheet.freeze` → WASM → Rust Sheet 的 `{ rows, cols }` → 同一次响应里的可见投影。

- 配置只存两个整数；冻结不改值、格式或公式，也不为冻结范围物化单元格。
- 原生历史只保留前后配置；无操作或无效输入不清 redo，不增加修订版。
- 在冻结带内部插入会扩大带，删除会缩小带；恰好在边界插入不改变冻结数。
  结构撤销/重做恢复原边界，移动工作表或删除后撤销仍跟随原工作表身份。
- 可选 `freeze` 快照字段保留配置；旧快照缺省为零。无效、重复或缺失表的配置拒绝整本恢复，
  原工作簿、历史不变。页面保存/打开入口仍未实现，不把绑定层快照当作 UI 持久化完成。
- 新增 `set_frozen_panes`、`frozen_panes` 两个 WASM API，同步更新增量签名快照并通过检查。
- Worker 在写入前校验 JS 整数、当前画布及投影所属表；Rust 操作失败时不发布新投影。
- 传输入口原有 296 行；按单文件规则将新增／重命名处理移至 `sheet-edit.ts`，入口现为 283 行。
  该文件只是已有协议处理，不是 backend、adapter 或另一个运行时。

## 冻结数据投影（2026-09-09）

- 请求可携带数据区域的四个实测像素值；Worker 按 Rust 冻结计数和原生稀疏尺寸计算固定区。
  滚动区、顶部、左侧和左上角共用一个响应及修订版，没有新增数据 atom 或二次刷新。
- 冻结前缀仅读取稀疏行列尺寸；内容与格式按屏幕所需的小矩形读取，隐藏行列切段跳过。
