## 本批：原生编辑历史

按钮/网格快捷键 → `runRustHistoryAtom` → 一次 `history.apply` → Rust 恢复源数据并返回当前投影。
历史源数据、公式源及稀疏样式仅在 Rust 保存；UI Core 直接派生投影中的标签与计数，
只另外保存历史弹窗的打开、忙碌、错误状态。React 负责按钮、列表及焦点，不回放数据。
单格快照直接查询该格及相关行列元数据，不扫描全表样式；多格操作记录目标范围内的稀疏条目。
行/列格式须覆盖其完整轴，以还原交叉样式覆盖；一次清除的格式/内容归入同一步。
恢复源值和公式由既有 Rust 依赖图重新计算，当前查看的工作表不自动跳走。

支持单格输入、格式、三种清除、行列尺寸。最多 50 步，并按约 32 MiB 的快照估算预算淘汰旧记录。
新修改丢弃重做分支；无变化的提交不增加历史，也不丢弃重做。初始化导入不属于用户操作。
历史仅限当前会话，不是持久化版本。复制、切换工作表保留历史；工作表结构修改仍会清空历史
并显示原因，失败不清空；粘贴历史已由下一批接通。不能把编号 15/36 标为全完成。
样例复用 E2→G2→Summary 公式、A4 文本编号、第 2 行格式及 Summary 原始尺寸，不预造历史记录。

## 本批：剪贴板历史

现有粘贴命令 → Rust 粘贴预检 → 记录实际写入范围 → 写入并返回含历史目录的投影。
复用原生预检，不在 JS 重算目标，不增加第二次 Worker 请求，也不创建工作簿数据镜像。
普通粘贴、七种模式、转置/跳过空白/平铺，以及同表剪切移动均归为一条历史。
剪切记录源区、目标区和真正被改写的跨表公式；撤销在一个 Store batch 中恢复。
两个不连续区域之间的空隙不进入快照；跳过空白按实际连续写入段记录，保留未触及的 spill 格。
格式粘贴历史不读写值或触发公式计算。UI 权限检查覆盖历史中的所有受影响工作表。
剪切成功后仍为一次性消费；undo/redo 回放原生历史，不再次执行剪切，也不重新授权旧剪切。
历史目录显示 Paste cells / Move cells。复用 A2 粗体、A4 文本编号、E2/G2 及 Summary 公式样例。

格式模式不计算及不连续区间隔离；相关页面专项 15 条通过。全量真实 Worker E2E 137/137 通过，
UI Core + React 全量 173 文件 / 2364 测试通过；Rust Core 1628 通过 / 3 条既有忽略，

展现层边界、文档和 diff 检查通过。桌面/390px 截图已检查，沿用上述 Playwright QA。
