## 已接入的原生链路

`range.merge` → `WasmWorkbook.merge_cells` → Rust 合并及历史 → 同次 Worker 响应中的投影。

- 合并矩形只存于 Rust Sheet，不写进 cellStyle，不创建覆盖格 atom。
- 左上角保留原始值或公式；其它非空内容必须明确确认才删除。
- 合并后居中与清除其它内容共用一条原生历史。
- 取消合并不恢复被清掉的数据，撤销合并才恢复；取消合并历史只存几何，不复制原始值或格式。
- 合并范围参与行列插删与结构撤销，数组公式不能跨越合并格。
- 取消合并后重新投影受阻数组；撤销取消合并会重新阻挡数组并清除其旧投影子格。
- `set_cell_input` 拒绝覆盖格输入，避免生成不可见数据；锚点输入仍使用现有编辑链路。
- Worker 不维护合并副本；一次动作返回原生历史与可见投影，确认拒绝或无操作不增加版本。
- 全表合并范围用于屏幕外导航；只读取与视口相交的锚点内容及格式，不枚举整个合并区。
- 窗口外锚点单独放在 `mergeAnchors`，不放宽普通 `cells` 的窗口边界约束。
- `initialize-workbook.ts` 承接工作簿初始化，Worker 主入口保持 ≤300 行。
