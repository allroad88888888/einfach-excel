# 手动选择多个不连续区域

在没有链接的单元格上，按住 Ctrl 或 Command 点击可追加一个单元格，按住同一修饰键拖动可追加矩形。松开修饰键后，本次拖动仍只更新新矩形；先前区域保持原样。普通点击恢复一个区域。

新区域为主区域：名称框显示该矩形，焦点位于本次拖动终点。重复点击相同单元格只将它设为主区域，不取消选择；若从重复单元格拖开，则保留原单元格并新增矩形。部分重叠的矩形独立保留，单元格计数和 Rust 数值统计按并集去重。松手后，相同矩形合为一个，保留本次主区域的锚点和焦点方向。

Shift 优先于追加，沿当前主区域的原锚点扩选。公式引用拾取优先写入原公式草稿；格式刷启用时仍使用一个连续目标。Ctrl/Command 点击外部超链接继续打开链接。

Escape 先遵循已有编辑和公式引用的取消规则；在网格导航中结束追加拖动并保留主区域，清除其它区域。浏览器取消指针、切换工作表、替换工作簿、结构变化或其它命令改变当前选区后，旧追加拖动不能继续写入。取消保留最后一个合法选区。

区域预算沿用现有上限 10,000。达到上限时，新的区域被拒绝，原有选择保留，并显示可读错误。已经选中的相同区域仍可激活。计数只处理矩形边界，不展开全表单元格。

清除和格式操作复用既有多区域 Rust 命令，区域之间的空隙不属于操作目标。边框仍沿用已有“需要一个连续区域”限制。选区是当前工作簿视图的会话状态，不写入导出文件，也不产生 Undo 历史；格式或清除产生自己的原生事务历史。

实现调用链：DOM `useGridPointerSelection` → Core `startPointerSelectionAtom` / `updatePointerSelectionAtom` → `selection/multi-range/pointer-append.ts` → 现有 selection authority → 现有多区渲染。新模块只记录拖动所有权凭证与预算反馈，不维护第二份选区。
