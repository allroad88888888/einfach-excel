# 单元格备注

选中单个单元格（合并区域使用锚点）后，工具栏的 Note / 备注打开原生备注。
新增、查看、保存、删除使用真实 Rust Worker。正文为纯文本，保留多行及首尾空格；换行统一为 LF。

- 上限为 32767 个 Unicode scalar，emoji 按一个字符计；超过上限显示明确错误，草稿保留。
- 仅空白文本不能保存。要移除已有备注，请使用 Delete note / 删除备注；未保存草稿不影响删除目标。
- Cancel / 取消与 Escape 丢弃草稿，不创建历史。保存期间防止重复提交；读取期间允许取消。
- 每次新增、修改、删除最多产生一条原生历史，Undo / Redo 恢复备注正文与标记。
- 标记来自 Rust 的 `noteIndicator`，空内容单元格也可有备注。普通值/公式编辑保留备注。
- 备注不改变值、公式、格式、超链接或同格线程批注。行列插删与工作表移动/重命名/删除历史保留对应语义。
- 原生 `.einfach.json` 的 v1 可选 `notes` 字段持久化正文。旧文件无该字段时为空；非法/重复条目拒绝整个文件并保留当前工作簿。

界面沿用已有 dialog-focus 与 CSS token，在 1280px / 390px 使用同一模态对话框。
持久 E2E 位于 `e2e/notes/`；独立功能登记及真实执行/截图由共享合流任务完成。
