# 工作表编辑保护

工具栏「工作表保护」可以把当前选区设为可编辑范围，再保护或取消保护当前工作表。
先取消保护才能增删可编辑范围。取消保护保留已配置范围；配置上限为每表256个矩形。
相邻或重叠矩形按并集判断，只有全部实际写入位置都允许编辑时才提交。

这是无密码的编辑保护，用于避免意外修改。它不加密文件，不隐藏数据，也不是保密或身份验证边界。

## 权限

- 受保护的锁定格拒绝值、公式、备注、批注、超链接、清除、格式、粘贴、剪切和填充。
- 可编辑区域允许普通内容、格式、备注、批注和超链接操作；边框会改邻格共边，因此邻格也必须可编辑。
- 行列和工作表结构、名称、Table定义、验证规则、条件规则、尺寸、隐藏、分组、冻结和筛选配置需要取消保护。
- Table内部可编辑格可普通输入；保护时不自动扩表或生成整列公式。表头改名和激活空Table输入行属于定义变更。
- 复制、读取公式帮助、导航、只读预览和重新计算允许。重新计算可更新公式结果，不修改公式源。
- 批量操作先检查全部实际写入范围，包含剪切源、跨表引用改写和边框邻居；失败保持内容和历史位置。

## 历史与文件

保护开关和可编辑范围设置不进入内容撤销栈。Undo/Redo按当前保护重新检查原生历史的实际目标，
不能用旧历史绕过保护；拒绝时Undo/Redo位置不变。取消保护后可继续原有历史。

允许范围按稳定工作表key保存，工作表改名或移动不会换错保护对象。行列插删时范围跟随几何；
结构Undo/Redo只移动当前范围，不回滚之后新设置的权限。被完整删除的允许范围不会通过内容Undo重新授权，
恢复单元格后需重新指定允许编辑范围。

原生 `einfach-workbook` 文件的workbook-v1扩展字段为 `protection`：

```json
{"protection":[{"sheet":0,"protection":{"mode":"protected","unlockedRanges":[
  {"rowStart":1,"rowEnd":2,"colStart":1,"colEnd":3}
]}}]}
```

旧文件缺少该字段时所有表默认开放。恢复先验证全部保护配置，在新工作簿内容恢复后最后安装权限，
然后一次替换当前文件；无效范围、重复表条目、缺失表引用拒绝整个打开操作。

## 实现与验收

React `ProtectionTools`只渲染面板、派发命令、管理对话框焦点。
Core `runNativeProtectionAtom`保存临时面板状态，经`protection.read/change`调用当前Rust Worker。
Rust `Workbook`是保护事实及所有写入检查的权威；Core旧保护atom是返回投影，供按钮和编辑预检使用。

专项测试覆盖原生绕过入口、批量原子拒绝、历史、几何、Core异步请求和React加载/保存/失败/焦点。
持久E2E在 `e2e/protection/`，每个操作独立，桌面1280和窄屏390；语言切换及原生下载/打开另有独立场景。
浏览器运行、WASM构件和截图由共享接线任务统一完成，未执行前不视为通过。
