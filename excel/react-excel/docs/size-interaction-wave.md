## 已接入：两种拖拽

- 表头底边／右边提供可聚焦手柄；普通表头与冻结表头共用组件。
- 拖动只更新 UI Core 的参考线草稿，松手复用 `runSelectionSizeAtom`，只发一次 `range.resize`。
  Rust 返回尺寸与同次可见投影，不增加二次刷新或 React 尺寸副本。
- 行高只写行属性、列宽只写列属性。拖动所选连续行／列中的边界，整组选中项统一成目标尺寸；
  拖其它边界只改该行／列，不把普通矩形选区扩大成批量尺寸修改。
- 原位点击、Escape、pointercancel、丢失捕获及窗口失焦不写入。手势期间表身份或尺寸元数据变动时拒绝过期提交。
- 尺寸沿用现有范围：行 16–512px、列 40–1024px；方向键可每次调整 10px。
- 手柄负责 DOM 捕获；`resize-drag.ts` 负责手势草稿及一次提交；`ResizeGuide` 负责在统一视口画参考线，
  避免被冻结表头裁掉。既有尺寸弹窗命令增加直接目标入口，拖动不会打开弹窗；失败提示仍可见。
- 保留既有 Summary 40px 首行、200px 首列作为原生尺寸示例；复用 Orders 大字体导致的非等高行检查撤销。

## 自动适应接入（2026-09-09，未提交）

- 双击行底边／列右边，或聚焦手柄按 Enter；整组选中行列各自适应自己的内容，不统一成同一尺寸。
- 最短链路：`GridResizeHandle` → 既有表头／尺寸 command atom → 一次 `range.resize` → 原生自动适应 → 返回尺寸及投影。
- `read-auto-fit-layout.ts`：读取一个无格式临时格的默认字体、行距、内边距与边框，随即移除。
  这是 DOM 测量，不读取当前挂载单元格的内容，也不把某个大字格当作全表默认字体。
- `auto-fit-measurement.ts`：每次命令共用一个 OffscreenCanvas，按 Rust 给出的有效格式量文字；
  数字显示复用可见投影的格式化函数。覆盖字体大小、粗斜体、缩进、边框、多行、中英文断行和旋转尺寸计算。
- `auto_fit_dimensions.rs`：复用 Workbook 稀疏读取，包含离屏内容与跨表公式结果；按目标轴汇总最大值。
  所有测量成功后才写行高或列宽，失败不留半次写入；不为整张空表生成默认尺寸条目。
- 隐藏列、手动／筛选隐藏行不参与测量，保存的尺寸与隐藏状态保留。跨被调整轴的合并格所在行／列
  保留原尺寸，不擅自分摊；仅横向合并的单行可以用合并后的总宽度自动适应行高。
- 非空内容可以缩小尺寸，仍受行 16–512px、列 40–1024px 上限约束；空行列恢复默认。
  一组操作只增加一条原生历史；重复得到相同尺寸不新增撤销记录。
- Summary 原生种子：E90 为 14px 粗体离屏长文本，F90 为斜体中英文三行，H90 为带千分位的跨表公式结果。
- 验收发现并修复两处现有视口问题：换表保留浏览器测得的可见面积；冻结时角按钮显式占第一行第一列，
  避免它被自动排格拉高后遮住行号。窗口缩放 E2E 等待 ResizeObserver 的实际尺寸后再导航。

## 手工验收

1. 任意行底边、列右边拖动：参考线跟随，松手再改变真实尺寸；Escape 取消，Undo 恢复。
2. 切到 Summary，在首屏双击 E 列右边：即使 E90 未挂载，列宽也应容纳它的长文本；再定位 E90 查看。
3. 定位 F90，双击第 90 行底边或聚焦手柄按 Enter：三行文字完整显示；选择 E:F 后自动适应并 Undo，应一次恢复两列。
