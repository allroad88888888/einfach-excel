## 已接入：两种拖拽

- 表头底边／右边提供可聚焦手柄；普通表头与冻结表头共用组件。
- 拖动只更新 UI Core 的参考线草稿，松手复用 `runSelectionSizeAtom`，只发一次 `range.resize`。
  Rust 返回尺寸与同次可见投影，不增加二次刷新或 React 尺寸副本。
- 行高只写行属性、列宽只写列属性。拖动所选连续行／列中的边界，整组选中项统一成目标尺寸；
  拖其它边界只改该行／列，不把普通矩形选区扩大成批量尺寸修改。
- 原位点击、Escape、pointercancel、丢失捕获及窗口失焦不写入。手势期间表身份或尺寸元数据变动时拒绝过期提交。
- 尺寸沿用现有范围：行 16–512px、列 40–1024px；方向键可每次调整 10px。
- 手柄负责 DOM 捕获；`resize-drag.ts` 负责手势草稿及一次提交；`ResizeGuide` 负责在统一视口画参考线，
  避免被冻结表头裁掉。既有尺寸弹窗命令增加直接目标入口，拖动不会打开弹窗；失败提示仍可见。
- 保留既有 Summary 40px 首行、200px 首列作为原生尺寸示例；复用 Orders 大字体导致的非等高行检查撤销。
