## 使用与数据规则

- 选中任意范围，底部显示 Numerical count / Sum / Average；原先的几何格数改名 Selected，避免混淆。
- Summary `A93:F93` 包含 10、0、-4、公式 `=A93*2`、文本 `30`、布尔 true；初始结果为 4、26、6.5。
  把 A93 改为 20 后变为 4、56、14；撤销、重做跟随 Rust 原生版本刷新。
- 统计完整选区，不限可见窗口或查询页；重叠区域只计一次，数值公式、溢出格与隐藏格都参与。
  文本数字、布尔、错误、非有限数不参与。合并区域只保留原生锚点数据，不按覆盖格重复计数。
- 没有数值时计数为 0，其余为 —；求和超出 f64 范围显示 Out of range，不假造零。
  有限平均值不因求和溢出丢失。结果仍是浮点统计，不宣称十进制任意精度。
- 原生最多接受 1024 个合法选区；超限或非法坐标整次报错，不返回前一部分统计。
  当前 React 仍是连续选区 UI，本批不顺带增加非连续多区选择入口。

## 最短调用链

选区／数据版本变化 → UI Core `selectionAggregatesAtom` → `selection.aggregate` → Rust → 统计结果 → React。

- Rust `workbook_aggregate.rs`：读取原生稀疏数值并计算结果；WASM 文件只转换参数、空值与结果。
- UI Core `selection-aggregates.ts`：只读派生查询，过时 Promise 由 atom 处理，没有 ticket、控制器或新数据副本。
  单独派生数据 revision，使同一版本的滚动不触发整列重查。没有连接时同步返回 idle，不制造无用等待。
- React `SelectionStatus.tsx`：只展示、格式化结果；Suspense 只包统计，不包网格。无需额外 useEffect 或 command 包装只读查询。
- 旧 TS 可见格算术、投影快照、截断预算、未接入配置及旧契约测试已删除，可从 Git 恢复。
  新测试覆盖原生数值与异步派生，不为暂停的 Solid 保留兼容代码。
- Worker runtime 触及文件上限，错误序列化移入已有 `transport.ts`，与响应端错误转换放在一起；Worker 仍只有三个源文件。
