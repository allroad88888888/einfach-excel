# 状态栏

`selectionAggregatesAtom` 是只读异步派生：读取当前选区、Rust 连接、投影的数据版本，
发出一次 `selection.aggregate`，返回非空计数、数值计数、求和、平均值、最小值、最大值。React 直接读取 atom，
仅给统计组件设置 Suspense，网格不随统计等待。

Rust 读取完整选区的稀疏数据，重叠区域只计一次；数值摘要计入数值公式，排除文本、布尔、错误。
非空计数包含文本、布尔、错误及空字符串，排除真正空白。隐藏格仍属于选区。
空选区两项计数为 0，其余为 null；求和溢出也返回 null，UI 明确提示。
滚动不改变数据版本，因此不重算；写入、撤销、重做返回的新版本触发重新查询。

文件职责：`types.ts` 定义结果；`selection-aggregates.ts` 派生查询；`index.ts` 是公开入口。
旧的 TS 可见格统计、投影副本、截断预算及未接入配置已删除，不为暂停的 Solid 留兼容层。
