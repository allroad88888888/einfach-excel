# 合并计算插件（`@einfach-excel/plugin-data-consolidate`）

为工作簿数据选项卡提供可选的 **合并计算（Consolidate）** 入口与配置对话框。

## 支持能力

- **11 种汇总函数**：求和、计数、平均值、最大值、最小值、乘积、数值计数、样本标准差、总体标准差、样本方差、总体方差。
- **按位置与按分类合并**：支持首行标签、最左列标签与二维交叉标签匹配（忽略大小写并按首次出现顺序合并）。
- **跨表与命名区域引用**：可添加 1–32 个来源区域（支持 `Sheet2!A1:D5`、`'Q1 Sales'!A1:C8` 与工作簿命名区域）。
- **创建指向源数据的链接**：在目标表生成跨表明细引用公式、汇总行公式及可折叠行分级大纲，源表更新后自动重算。
- **预览与覆盖确认**：写入前预览目标范围和抽样结果，如覆盖已有内容需显式确认；单步撤销/重做原子恢复单元格与大纲。

## 在演示站启用

通过 `?plugins=data-consolidate` 挂载本插件；未挂载时核心界面不包含该按钮或对话框。
