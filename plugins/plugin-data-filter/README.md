# 筛选条件插件

`dataFilterPlugin` 为现有筛选面板提供前 / 后若干项、日期期间编辑器。宿主通过
`<Spreadsheet plugins={[dataFilterPlugin]} />` 安装；演示地址参数为 `?plugins=data-filter`。

插件的 `filterConditions` 贡献同时出现在功能区与普通区域、Table 的表头入口。
插件拥有 Top / Bottom、Items / Percent、Date period 字段与编辑命令。共享面板仍拥有列选择、
条件组、焦点、取消与提交生命周期，基础四类条件的编辑器仍在核心。

调用链为字段事件 → 插件 Core 命令 → 共享条件草稿 → 原生筛选命令 → Rust 投影。
插件不读取单元格、不计算排名、不创建第二份筛选控制器。多个工作簿的草稿随各自
Einfach store 隔离；更换连接后，旧异步结果不能覆盖新连接的反馈。

- 项数接受 1–500 的整数，百分比接受 1–100 的整数。
- 原生引擎先在完整数据体内统计有限数值，再与其他条件求交集；文本数字不参与。
- 百分比名额向上取整，阈值处的并列行全部保留；表头与 Table 汇总行不参与。
- 编辑单元格不自动重筛，重新应用才更新隐藏快照；撤销恢复原快照。
- 原生文件保存条件与隐藏快照。不安装插件时仍可求值、重新应用、保存；基础面板
  保留插件条件并提示启用对应插件，显式切换条件类型才替换它。
- 卸载插件会移除其字段，已编辑的共享草稿仍保留。应用会提交该草稿，取消会丢弃。
- XLSX 转换尚不映射筛选条件，导出报告会说明条件与筛选隐藏快照丢失，手动隐藏保留。
  导入外部文件的物理隐藏行会保留为手动隐藏，报告提示可通过取消隐藏恢复。

本包当前是仓内私有 workspace 包，尚未发布。

日期期间支持今天、昨天、明天，上/本/下周、月、季度、年，以及年初至今。
Rust 在每次应用或重新应用时捕获一次本地日期，复用条件格式的日历区间计算。
周从周日开始；区间包含起始日、排除下一期间起点，日期中的时间小数仍参与。
今年包含未来日期，年初至今仅到今天结束。条件不是绝对日期起止范围。

只匹配原生数值日期（包括公式结果），文本日期、布尔、错误、空白不匹配；
日期域为序号 `[1, 2958466)`，保留 Excel 的 1900-02-29，排除序号 0。
不安装编辑器仍可恢复、重应用和保存条件；跨午夜不自动重筛，文件恢复和撤销
直接恢复隐藏快照。XLSX 的 1904 日期只使用转换器已经归一化的值，不二次偏移。
Summary `H2:H9` 提供随 `TODAY()` 更新的原生日期示例。
