# 自定义列表排序插件

工作区中的可选业务包，尚未发布。宿主从包根入口导入 `dataSortPlugin`，通过
`<Spreadsheet plugins={[dataSortPlugin]} />` 挂载；演示地址参数为 `?plugins=data-sort`。

插件在普通排序入口后增加“自定义列表排序”，自己的 Core 入口管理对话框草稿与反馈。
界面只读取 atom、派发命令；核心不依赖插件，未安装时仍能读取、编辑、保存已排序的数据。

## 列表与排序语义

- 列表来自 UI Core 唯一的 `namedListDirectoryAtom`，与填充序列共享宿主配置及用户保存项。
  保存、编辑、删除列表仍在“填充序列”中完成；插件没有第二目录或浏览器存储。
- 每个级别可选择列表或普通单元格值；至少一个级别必须使用列表。最多八个不同列，
  按级别顺序比较；支持表头、大小写、空值位置、混合方向与优先级调整。
- Apply 重新读取选定来源，捕获 `values` / `locale` 快照，调用公开 `sortSelectionAtom`。
  所选来源删除或被用户同名列表覆盖时留在对话框报错，不自动换用其他来源。
- 原生只对 Text 值匹配列表，不把文字标签解析成数字或日期。升序时匹配值在前，未知值
  使用现有类型顺序；降序反转整个非空比较。真正空单元格的位置独立于方向，空字符串仍为文字。
- 列表与填充使用相同原生校验：2–512 个条目、合计最多 16384 UTF-16 单元、非空白且按
  locale 折叠后唯一。支持 en / zh / tr / az 的既定 canonical locale；保留宿主条目正文空白。
  区分大小写时按原文匹配，不区分时使用列表 locale 的折叠规则。
- 只移动选区矩形；筛选隐藏行固定原位，手动隐藏行参与。保护、合并、溢出拒绝与普通排序一致。
  排序走一次原生历史事务；重复相同结果不增加历史。
- 列表是工作簿会话选项，排序草稿属于插件当前连接。文件持久化物理排序结果，不保存列表目录
  或排序规则；替换连接后不会恢复旧草稿，旧请求不会改写新连接的反馈。

## 宿主显隐与边界

`ui.ribbon.hidden` 可隐藏 `data.custom-list-sort` 或整项贡献 `plugin:data-sort:custom-list`。
隐藏普通排序锚点不会隐藏本插件入口。插件继承所在组的分类与“更多”布局，面板挂载于工作簿根部。

当前包只交付列表排序编辑流程。普通排序编辑器仍在核心；颜色排序、图标排序不属于本次实现。
底层校验、行置换、公式搬移、历史和投影始终由核心负责。
