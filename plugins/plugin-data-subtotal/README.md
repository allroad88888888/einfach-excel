# Data Subtotal 插件

在宿主 `plugins` 数组加入 `dataSubtotalPlugin`，即可使用功能区的「分类汇总」。演示站使用 `?plugins=data-subtotal`。可以从 Summary 的 `A25:C29` 选择 Team 分类、Score 求和。

选择含标题的普通数据区域，或点选数据区域中的单格。分类按相邻记录的字段变化分组。可以选择 11 种汇总方式、多个输出列，以及汇总行在数据上方或下方。已有分类汇总支持替换、追加内层或汇总方式、全部删除。删除前校验生成行，保护用户随后写入的内容及仅应用于这些行的规则。

插件保存对话框草稿并提交命令。原生工作簿写入 `SUBTOTAL` 公式、变更行结构和大纲，并记录一次撤销。原生文件保留公式、折叠状态与生成行归属。移除插件后仍可打开工作簿、计算公式及操作大纲。XLSX 保留公式和行数据，通过既有导出报告提示大纲配置损失。
